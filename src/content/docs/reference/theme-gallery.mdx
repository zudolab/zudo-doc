Twenty-one theme packs ship with `@takazudo/zudo-doc`: the reserved `default` plus twenty designed looks. This page is the full catalog. For how packs work — the config fields, the switcher UI, the CLI, and the authoring contract — see [Theme Packs](./theme-packs.mdx).

Each entry shows the pack's **badge** (its designed-primary mode — a hint about which mode the pack was designed around, not a capability flag; every pack defines both modes and the header mode toggle works on all of them), its font stacks, and an apply snippet. Applying a pack is one move, done either way:

```sh
# via the CLI (rewrites themePack in zfb.config.ts)
pnpm exec zudo-doc theme apply <slug>
```

```ts title="zfb.config.ts"
// or set the field by hand
themePack: "<slug>",
```

One caveat: if your project sets an explicit `themePacks` list, that list is authoritative — a `themePack` slug it omits **fails the build loudly**. Add the slug to `themePacks` too (or drop the list to enable every bundled pack).

<Tip>

This showcase site has the switcher enabled — use the round launcher at the bottom-right of any page to preview every pack below live, or open its browse-all grid to compare them side by side without downloading a single stylesheet.

</Tip>

Packs are listed in the default switcher order: `default` first, the rest alphabetical.

## Default

The stock zudo-doc look. No pack stylesheet is loaded — your project's configured color scheme and fonts render unchanged, at zero extra requests.

- **Badge:** Dark
- **Fonts:** system stacks (nothing loaded)

```sh
pnpm exec zudo-doc theme apply default
```
