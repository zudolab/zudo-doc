Released: 2026-09-23

### Bug Fixes

- New projects ignore the `.zudo-doc/` route-source staging directory generated by package-owned routes (848264b9c). Existing projects scaffolded on 5.26.4 or earlier need to add this entry by hand after bumping — see the `@takazudo/zudo-doc` changelog for that release.
- Generated projects now pin `@takazudo/zudo-doc` and its history server to `^5.26.5`.
