Released: 2026-11-14

### Other Changes

- `create-zudo-doc` 12.0.0 was tagged but never published to npm: its publish-time scaffold pin freshness check refused the Wrangler 4.161.0 pin after Wrangler 4.162.0 was released. 12.0.1 is the first published 12.x release of `create-zudo-doc`; read the 12.0.0 notes when upgrading from 11.0.0.
- A fresh scaffold pins `@takazudo/zudo-doc` and `@takazudo/zudo-doc-history-server` at `^12.0.1`.
- MCP scaffolds pin Wrangler 4.162.0 instead of 4.161.0.
