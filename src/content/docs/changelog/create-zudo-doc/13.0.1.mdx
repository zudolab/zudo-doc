Released: 2026-11-19

### Other Changes

- A fresh scaffold pins `@takazudo/zudo-doc` and `@takazudo/zudo-doc-history-server` at `^13.0.1`, and `@takazudo/zfb`, `@takazudo/zfb-runtime` and `@takazudo/zfb-md-wasm` at 7.1.0. MCP projects also pin `@takazudo/zfb-adapter-cloudflare` at 7.1.0. 7.1.0 publishes the Linux arm64 npm CLI and CSS carrier again, so a Linux arm64 npm install of a new project receives `@takazudo/zfb-linux-arm64-gnu`. Linux x64, macOS and Windows npm installs are unchanged.
- Design-token-panel projects pin `@takazudo/zdtp` 0.9.9. 0.9.9 keeps the zfb peer `^5.1.2 || ^6.0.0 || ^7.0.0` and builds against zfb 7.1.0.
- MCP scaffolds pin Wrangler 4.165.0.
