## Other Changes

- Widened the optional `@takazudo/zdtp` peer range to `^0.5.2 || ^0.6.0 || ^0.7.0` and moved the showcase and scaffold pins to 0.7.0. The upstream changes are additive for this consumer: the four panel APIs remain available, and the public constants and shipped panel stylesheet are unchanged. zdtp 0.7.0 does carry one documented breaking change — `TokenDashboard` no longer derives its chrome appearance from `mode`, and needs an explicit `chrome` prop — but that component is not part of this consumer's surface, so no migration is required here. The panel bootstrap, vendored-constants conformance, and optional-peer reachability tests pass against 0.7.0. Projects must explicitly pull the panel stylesheet via `@import "@takazudo/zdtp/styles.css"`, as `create-zudo-doc` has always emitted; check this import if you hand-edited `global.css`. A downstream pnpm `peerDependencyRules.allowedVersions` exception for `@takazudo/zudo-doc>@takazudo/zdtp` can be dropped on this release.
