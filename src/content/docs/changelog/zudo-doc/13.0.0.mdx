Released: 2026-11-16

### Breaking Changes

- Require the ZFB 7.0.0 family (`^7.0.0`). ZFB 7 suspends the Linux arm64 npm CLI and CSS distribution, so a Linux arm64 npm install no longer receives `@takazudo/zfb-linux-arm64-gnu`. Linux x64, macOS and Windows npm installs are unchanged. Rust builds, GitHub Release archives and the standalone CLI still support Linux arm64. Removed bundler selectors must stay unset.
- A design-token panel needs `@takazudo/zdtp` 0.9.8 or newer. 0.9.7 and earlier do not accept the ZFB 7 peer.
- The `@takazudo/zudo-doc-history-server` peer floor moves from `^12.0.0` to `^13.0.0`. Projects that enable document history need history-server 13.x.

### Features

- New `<CategoryList>` component and repeatable `category-list` entry for `home.sections` list the first `limit` documents of one category, such as a blog, a numbered note tray or an ordinary category, as cards (up to three columns) or a two-column list, with an optional "See all" link to the full category. Items follow the category's own order and public navigation visibility; note trays keep their sidebar numbers and dates. Both layouts render on the server without client JavaScript. The `@takazudo/zudo-doc/category-list` subpath exports the resolver and view, and the agent export renders the component as a link list. (#4802)
