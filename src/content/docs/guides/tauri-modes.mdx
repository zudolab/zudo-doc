## What was retired

zudo-doc no longer includes native desktop app support. Both Tauri modes have been removed from the source:

- **Mode 1 — offline reader** (`src-tauri/`), which bundled a built site into a desktop app
- **Mode 2 — dev wrapper** (`src-tauri-dev/`), which wrapped a running dev server in a native window

`create-zudo-doc` no longer scaffolds either app, and the Tauri-only find-in-page feature (the `findInPage` setting and its Cmd/Ctrl+F find bar) is removed as well. In a browser, Cmd/Ctrl+F is the browser's own find again.

:::note[Older published versions]
This is a source-level removal. Package versions that were already published before the removal still contain the Tauri features and keep working as they did. The removal reaches a project only when it upgrades to a release that includes it, which is a major release because the change is breaking. There is no replacement desktop app, PWA, or offline product.
:::

## What to use instead

- **Writing and previewing docs:** run `pnpm dev` and open the site in a browser. See [Development](../getting-started/installation.mdx#development).
- **Checking a built site:** run `pnpm build`, then `pnpm preview` to serve `dist/` locally. See [Build](../getting-started/installation.mdx#build) and [Deployment](./deployment.mdx).

## Cleaning up an existing project

When a project that used either mode upgrades to a release without Tauri support, remove the old native pieces by hand:

1. **Generator selections:** drop `tauri` and `tauriDev` from saved JSON presets or programmatic `features` arrays, and drop `--tauri` / `--tauri-dev` from scripted `create-zudo-doc` commands. Enabling them is now an error. The disabling forms (`--no-tauri`, `--no-tauri-dev`, `--tauri=false`, `--tauri-dev=false`) are still accepted and do nothing. See [create-zudo-doc](../reference/create-zudo-doc.mdx#options-features).
2. **Config:** remove the `findInPage` field from the `zudoDoc({ ... })` call in `zfb.config.ts` (or from your settings object).
3. **Imports:** remove any direct import of `@takazudo/zudo-doc/find-in-page`. That export no longer exists.
4. **App files and scripts:** delete the `src-tauri/` and `src-tauri-dev/` directories, and remove the `dev:tauri`, `dev:tauri-dev`, `build:tauri`, and `build:tauri-dev` scripts from `package.json`, along with any helper scripts that only served them.

Nothing removes desktop apps that are already installed, or their per-user data. If you built one of these apps yourself and no longer want it, uninstall it the way you would any other app on your operating system.
