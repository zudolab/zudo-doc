`@takazudo/zudo-doc` には 31 のテーマパックが同梱されています。予約された `default` に、デザインされた 30 の見た目を加えたコレクションです。このページはその全カタログです。パックの仕組み — 設定フィールド、スイッチャー UI、CLI、オーサリング契約 — については[テーマパック](./theme-packs.mdx)を参照してください。

各パックのフォントは、記事本文だけでなくクローム全体 — ヘッダー、サイドバー、目次を含む — をスタイルするようになりました。

各エントリには、パックの**バッジ**（そのパックがどちらのモードを主として設計されたかのヒントであって、対応可否のフラグではありません — すべてのパックが両モードを定義しており、ヘッダーのモードトグルはどのパックでも機能します）、フォントスタック、そして適用スニペットを載せています。パックの適用はどちらの方法でも一手で済みます:

```sh
# via the CLI (rewrites themePack in zfb.config.ts)
pnpm exec zudo-doc theme apply <slug>
```

```ts title="zfb.config.ts"
// or set the field by hand
themePack: "<slug>",
```

1 つだけ注意点があります。プロジェクトで明示的な `themePacks` リストを設定している場合はそのリストが正となるため、リストに含まれていないスラッグを `themePack` に指定すると**ビルドが大きな声で失敗**します。そのスラッグを `themePacks` にも追加してください（あるいはリスト自体を外せば、同梱パックがすべて有効になります）。

<Tip>

このショーケースサイトではスイッチャーが有効になっています。どのページでも右下の丸いランチャーから、以下のすべてのパックをライブでプレビューできます。一覧グリッドを開けば、スタイルシートを 1 枚もダウンロードせずに見た目を並べて比較できます。

</Tip>

パックはスイッチャーのデフォルト順 — `default` が先頭、残りはアルファベット順 — で並べています。

## Default

zudo-doc 標準の見た目。パックのスタイルシートは読み込まれず、プロジェクトで設定したカラースキームとフォントがそのまま描画されます。追加リクエストはゼロです。

- **バッジ:** Dark
- **フォント:** システムスタック（何も読み込みません）

```sh
pnpm exec zudo-doc theme apply default
```

## Academia

Web に載せた LaTeX 論文 — 白いページ、Computer Modern を思わせる黒インク、hyperref のネイビーリンク、番号付きの定理スタイルのアドモニション、booktabs のテーブル。ダークモードは学究的なスレート。

- **バッジ:** Light
- **フォント:** Source Serif 4（本文）· Courier Prime（mono）

```sh
pnpm exec zudo-doc theme apply academia
```

## Bauhaus

三原色が構造になる — ギャラリーの白、ほぼ黒のインク、そして構造の仕事を担う赤・黄・青。丸・三角・四角のマーカー、太い幾何学的な罫線、角丸ゼロ。

- **バッジ:** Light
- **フォント:** Archivo Black（display）· Jost（sans）· Space Mono（mono）

```sh
pnpm exec zudo-doc theme apply bauhaus
```

## Beacon

WCAG AAA の高コントラスト — 全域 7:1 以上のインク、3px のフォーカスリング、常に下線の付いたリンク。明瞭さこそ美しさ。

- **バッジ:** Light
- **フォント:** Atkinson Hyperlegible（sans）· Atkinson Hyperlegible Mono（mono）

```sh
pnpm exec zudo-doc theme apply beacon
```

## Blueprint

- **バッジ:** Dark
- **フォント:** Josefin Sans（display）· Inter（sans）· IBM Plex Mono（mono）

```sh
pnpm exec zudo-doc theme apply blueprint
```

- **バッジ:** Light
- **フォント:** Cormorant Garamond（display）· Crimson Pro（本文）· Courier Prime（mono）

- **バッジ:** Light


## Futura Editorial
