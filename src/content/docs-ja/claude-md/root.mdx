# zudo-doc

zfb、MDX、Tailwind CSS v4、Preactアイランドで構築された最小限のドキュメントフレームワーク。

（もともとAstro 6をベースに構築。zfbへの移行はepic zudolab/zudo-doc#1333で実施。長文の散文ではAstroツールへの歴史的な言及が残ることがあるが、それらは過去の状態を説明するものであり、現在の推奨アーキテクチャではない。）

## Tech Stack

- **zfb** (`@takazudo/zfb`) — MDXコンテンツコレクション、ファイルベースルーティングの`pages/`、組み込みのdev/build/preview/check CLIを備えた静的サイトジェネレーター。設定は`zfb.config.ts`
- **MDX** — `src/content/`以下で管理。コンテンツディレクトリは`docsDir`設定で変更可能
- **Tailwind CSS v4** — `@tailwindcss/vite`経由
- **Preact** — インタラクティブなアイランド（TOCスクロールスパイ、サイドバートグル、折りたたみカテゴリ）とサーバーレンダリングされたコンテンツタイポグラフィコンポーネントに使用。React API互換のcompatモードで動作
- **syntect** — 組み込みコードハイライト。zfbのRustパイプラインでビルド時に実行（固定テーマ：`base16-ocean-dark`）。各カラースキームの`shikiTheme`フィールドは、zdtpパネルのクライアントサイドShikiプレビュー専用のランタイム設定
- **@takazudo/zudo-design-token-panel (zdtp)** — Design Token PanelのUIを提供する外部npmパッケージ。`src/lib/design-token-panel-bootstrap.ts`内の`configurePanel(designTokenPanelConfig)`で組み込む。サイドエフェクトとして自己マウントされる（Preactアイランド登録不要）
- **TypeScript** — 厳格モード（プロジェクトの`tsconfig.json`に`strict: true`と`strict*`フラグ群を直接設定）

## Commands

- `pnpm dev` — zfb dev（ポート4321）とdoc-history-server（ポート4322）を`run-p`で並行実行（predevが当該ポートのスタレプロセスをキル）
- `pnpm dev:zfb` — zfb devサーバーのみ（ポート4321）
- `pnpm dev:history` — doc history APIサーバーのみ（ポート4322）
- `pnpm dev:stable` — ビルド後サーブのdev代替モード（コンテンツファイルの追加/削除時のHMRクラッシュを回避）
- `pnpm dev:network` — `--host 0.0.0.0`付きのzfb dev（LAN接続用）
- `pnpm build` — `dist/`への静的HTMLエクスポート（`zfb build`を実行）
- `pnpm preview` — ビルド済み`dist/`をサーブ（`zfb preview`を実行）
- `pnpm check` — 型チェック（`zfb check`を実行、`tsc --noEmit`に委譲）
- `pnpm b4push` — プッシュ前検証：フォーマットチェック → テンプレートドリフトチェック → タグ監査（`tags:audit --ci`）→ デザイントークンリント → 型チェック → ビルド → リンクチェック → プレビュースモーク

## Conventions

### Components

- すべてのコンポーネントは**Preact `.tsx`** — `.astro`ファイルは存在しない。ページ、レイアウト、コンポーネントオーバーライドはすべてPreact関数コンポーネントとして記述
- デフォルトは**サーバーレンダリングPreact**（`client:*`ディレクティブなし）— 静的マークアップでJSゼロ
- インタラクティビティが必要な場合のみ**クライアントアイランド**に昇格。zfbのハイドレーションは`ssr-islands.tsx`レジストリや標準的な`client:*`スタイルのプロップで明示的に有効化
- 現在のクライアントアイランド：`toc.tsx`、`mobile-toc.tsx`、`sidebar-toggle.tsx`、`sidebar-tree.tsx`、`theme-toggle.tsx`、`doc-history.tsx`、`find-bar.tsx`、`image-enlarge.tsx`、`ai-chat-modal.tsx`、zdtpパネル（`configurePanel()`によるサイドエフェクトで自己マウントされ、アイランドレジストリへの登録は不要）
- コンテンツタイポグラフィコンポーネント（`src/components/content/`）：`pages/_mdx-components.ts`の`<Content components={...} />`マッピングを通じてMDXが出力する標準HTML要素をオーバーライドする、サーバーのみでレンダリングされるPreact関数コンポーネント。h2〜h4、paragraph、link、strong、blockquote、lists（ul/ol）、tableを含む

### Content Collections

- スキーマとコレクション設定は`zfb.config.ts`（Zodバリデーション）
- 設定からの構成可能な`base`ディレクトリを持つzfbのMDXコンテンツパイプラインで読み込み
- コンテンツディレクトリ：`docsDir`（デフォルト：`src/content/docs`）、`docsJaDir`（デフォルト：`src/content/docs-ja`）

### i18n

- 英語（デフォルト）：`/docs/...` — `docsDir`のコンテンツ（デフォルト：`src/content/docs`）
- 日本語：`/ja/docs/...` — `docsJaDir`のコンテンツ（デフォルト：`src/content/docs-ja`）
- `zfb.config.ts`で`prefixDefaultLocale: false`として設定
- 日本語ドキュメントは英語のディレクトリ構造をミラーする必要あり
- **バイリンガルルール**：ドキュメントページを作成・更新する場合は、英語版と日本語版の両方を更新すること。コードブロックは同一に保ち、散文のみ翻訳する
- **例外**：フロントマターに`generated: true`があるページは日本語翻訳が不要
