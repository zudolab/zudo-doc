リリース日: 2026-06-12

### バグ修正

- スキャフォールドされる `_toc-title.ts` テンプレートを `@takazudo/zudo-doc/toc` からの re-export に切り替え。パッケージが `getTocTitle` をエクスポートするようになった現在、手動でミラーしていた `TOC_TITLES` マップは構造的に古くなる宿命だったため削除 (f3a9b058)
- `DiffViewer` を比較リビジョンペアで key 付けし、デスクトップで新しい Compare ペアを選んだときにビューアを再マウントするように修正 — 新しいヘッダーのハッシュが前のペアの古い diff 行の上に一瞬表示される問題を解消 (e6d39bb9)

### その他の変更

- zfb ファミリーを 0.1.0-next.41 にバンプ — 非 index ページから書かれた dir 形式 href の URL 空間フォールバックを追加し、データファイルのスキップ警告がコレクションの include/exclude glob を尊重するように (cbab69c5)
