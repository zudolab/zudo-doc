新しいリリースパイプラインで公開する最初のプレリリースです。以前の `0.1.0` の公開を置き換え、`X.Y.Z-next.N` 形式のプレリリースバージョニングでバージョン管理を再始動します。

### 変更点

- **npm リリースチャンネル。** プレリリースは `next` dist-tag で公開されます。プレリリース期間中は `latest` も最新のプレリリースを指すため、`npm install` が古いバージョンに取り残されることはありません。安定版を公開すると、この挙動は自動的に無効化されます。
- **ロックステップバージョニング。** `@takazudo/zudo-doc`、`@takazudo/zudo-doc-history-server`、`create-zudo-doc` は同じバージョンで足並みをそろえて更新され、新規に生成したプロジェクトは対応する `@takazudo/zudo-doc` のバージョンをピン留めします。
