リリース日: 2026-06-12

### 機能

- ロケール→TOC タイトルのリゾルバ `getTocTitle` を公開バレル `@takazudo/zudo-doc/toc` からエクスポート (aa3741eb)

### バグ修正

- `search-index.json` の読み込み失敗後、検索ウィジェットがキーストロークごとにインデックスを再フェッチしてメッセージがちらつく問題を修正 — 「Search unavailable」を安定して表示し、リトライ時は正常に復帰 (47334892)
- AiChatModal と ImageEnlarge の body-end アイランドを機能フラグでゲートし、機能オフのコンシューマーに不要なアイランドマーカーや誤解を招くスクリーンリーダー用「AI Assistant」ランドマークが出力されないように修正 (29417afa)
- 閉じたモバイルサイドバードロワーを `inert` にし、画面外のリンクやフィルター入力がタブ順序とアクセシビリティツリーに残らないように修正 (6caa7f80)
- 不要な Sidebar アイランドマーカーを抑止し、同期されたコンシューマーでの Toc/MobileToc のハイドレーションを復旧 (d27c653d, c2cb4f83)

### その他の変更

- スキャナー可視の Toc/MobileToc/ThemeToggle シムを撤去 — zfb 0.1.0-next.39 以降は npm 配布物の `"use client"` モジュールをスキャンするため、パッケージのアイランドが直接登録され、シムはマーカー名の衝突を起こすようになったため (241b8a41)
- zfb ファミリーを 0.1.0-next.40 に更新 (cc7ec7c8, f31e0ea2)
- 0.2.0 → 0.2.1 のコンシューマー向け移行ノートをチェンジログに追加 (9ee33dbf, d69d225d)
- CI ドキュメントから Cloudflare 10013 インシデントの注記を削除し、wrangler を `@4` にフロートし直し (d050c9cb)
