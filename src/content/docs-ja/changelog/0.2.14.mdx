リリース日: 2026-06-19

### 機能

- 検索エンジンのインデックスを避ける機能を追加しました。ジェネレーターの機能として `noindex` トグルを選択できるようになり、有効にすると検索エンジンにインデックスしないよう求める `robots.txt` ページルートがスキャフォールドされます。(#2218, #2219)
- PresetGenerator の UI で、各機能の隣にドキュメントへのリンクが表示されるようになりました。スキャフォールドの設定中に該当ガイドへ直接ジャンプできます。(#2220)
- ジェネレーターで category-top + `CategoryNav` のナビゲーションパターンをスキャフォールドできるようになりました。子ドキュメントを紐づけたカテゴリのトップページが生成されます。(#2230)

### バグ修正

- サイドバーのリサイザーが、手動でドラッグした幅を SPA（クライアントルーター）ナビゲーションをまたいでも保持するようになりました。View Transition による遷移後に幅がリセットされる問題を修正しています。(#2231)

### その他の変更

- ドキュメント: バイリンガル（EN + JA）の「検索エンジンのインデックス回避」ガイドを追加しました。`noindex` 機能と生成される `robots.txt` ルートを説明するクロスリンク付きです。(#2221)
- ドキュメント: ナビゲーション設計スキルと structuring-navigations ガイドで、category-top + `CategoryNav` の慣習を解説しました。(#2230)
