リリース日: 2026-11-16

### 破壊的変更

- 新規スキャフォールドは `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` を `^13.0.0` に、`@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-md-wasm` を 7.0.0 に固定します。MCP プロジェクトは `@takazudo/zfb-adapter-cloudflare` も 7.0.0 に固定します。ZFB 7 は Linux arm64 向け npm の CLI と CSS 配布を停止したため、新規プロジェクトを Linux arm64 で npm インストールしてもネイティブの実行ファイルは入りません。Linux x64、macOS、Windows の npm インストールは変わりません。
- デザイントークンパネルを有効にしたプロジェクトは `@takazudo/zdtp` 0.9.8 をピン留めします。この版は ZFB 7 の peer を受け入れます。MCP スキャフォールドは Wrangler 4.163.0 をピン留めします。
