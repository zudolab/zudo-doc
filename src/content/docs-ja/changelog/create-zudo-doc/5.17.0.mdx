リリース日: 2026-09-04

### 機能

- `check-links` がプロトコル相対URL (`//host/path`) を黙って見過ごすのではなく、情報通知として報告するようにしました (`67afa352f`)。

### バグ修正

- `check-links` がプロトコル相対URL (`//host/path`) を壊れたローカルリンクとして扱わないようにしました (`319169bf3`)。

### その他の変更

- 新しく生成するプロジェクトがzfb 2.15.0のパッケージ一式を使用するようにしました (`d9f5b2f64`)。`ts`・`typescript` のコードフェンスがTypeScriptグラマーに、`tsx` がTypeScriptReactに解決されます。これまではいずれもJavaScriptのハイライトにフォールバックしていました。
