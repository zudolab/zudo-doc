リリース日: 2026-09-09

### バグ修正

- 生成プロジェクトのドキュメントスキル設定スクリプトを、macOS 標準の Bash 3.2 で動作するようにしました。ロケールと設定の扱いも修正し、ロケールの案内を出力する前にドキュメントへのシンボリックリンクが存在することを確認するようにしています。(`85b603e33`, `f6b699fe0`)
- 生成プロジェクトのリンクチェッカーで、引用符付きの属性値に `>` が含まれていても ID とリンクを正しく認識するようにしました。各ページを一度だけ解析することで、重複した走査も減らしています。(`0e52271b9`, `7c0144e51`)

### その他の変更

- Design Token Panel 機能が出力する `@takazudo/zdtp` の固定バージョンを `0.7.0` に更新しました。新しく生成するプロジェクトでは、移行作業なしで互換性のあるパネル連携を利用できます。(`e0fc27fbd`, `9554dbbea`)
