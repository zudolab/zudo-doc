### その他の変更

- 生成されるプロジェクトが `@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-md-wasm` の `2.19.0` を固定するようになりました。zfb 2.19 では、ビルド診断用の任意機能 `ZFB_KEEP_BUILD_SHADOW=1` が追加され、上流の全18件のベースラインケースで同等性を確認済みの YAML パーサーパッチが採用されています。runtime にはパッケージ固有の挙動変更はなく、md-wasm は成果物を再ビルドしていますが、エクスポートや公開 API は変わりません。既存プロジェクトの設定移行は不要です。（4c2048528）
