### その他の変更

- デザイントークンパネルを有効にすると、生成されるプロジェクトは `@takazudo/zdtp` 0.9.0 を固定するようになりました。パネルが Preact に依存しなくなったため、生成されるプロジェクトには Preact がインストールされません。汎用トークンタブで元に戻すと、`:root` から編集値も消えるようになりました。
- `zudo-doc-writing` スキル（`claudeSkillsWriting` 機能）は、ナビゲーションを設定する前に、作りたいサイドバーのツリーと各遷移先のふるまいを書き出すよう求めるようになりました。ヘッダーのドロップダウン、共有のサイドバー階層、厳選した編集上のツリー、傘のツリーを区別し、ドロップダウンやセクションページの一覧ではサイドバーの親ができないことを注意します。
