### その他の変更

- 生成されるプロジェクトが `@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-md-wasm` の `2.21.1` と `@takazudo/zdtp` の `0.8.3` を固定するようになりました。zfb 2.21.1 の範囲には 2.20.3 のシングル Preact ランタイム SSR 修正、バンドラーのコレクションシードを各コレクションの `include` フィルターに限定する変更、そして 2.21.1 のバグ修正（`zfb dev` / `zfb build` の起動高速化と、編集されたワークスペースパッケージファイルでの SSR リロード）が含まれます。zdtp 0.8.3 は孤立した SPA ルートからパネルのマウントを復旧します。既存プロジェクトの設定移行は不要です。
