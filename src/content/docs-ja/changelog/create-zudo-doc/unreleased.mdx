### バグ修正

- 生成される `scripts/check-links.js` の MDX id スキャンで、地の文にあるエスケープ済みの `\<` が偽のタグを開始し、空行を挟んだ後にある別要素の静的 `id` を読み飛ばして、有効なアンカーを誤って「壊れている」と報告する不具合を修正しました。テンプレートから `scripts/check-links.js` をコピーしたプロジェクトは、再度コピーすることでこの修正を取り込めます。

### その他の変更

- 新しく生成されるプロジェクトは、生成される `.gitignore` に `.zudo-doc/` エントリを追加しなくなりました。これが必要だったステージング処理は `@takazudo/zudo-doc` のルート注入から削除されました。詳細は同パッケージの変更履歴を参照してください。
