リリース日: 2026-11-06

### 機能

- すべての生成プロジェクトに編集方針ファイル`AUTHORING.md`(読者、範囲、スキャフォールドの選択から事前入力したカテゴリー、最小限のページ配置手順)を追加し、そこへ案内する`AGENTS.md`と`README.md`も生成するようにしました。生成される`CLAUDE.md`にも同じファイルを指す「Documentation structure」セクションを追加しました。(0d162828, 947aa27f)
- スキャフォールドされる`zudo-doc-writing`スキルは最初に`AUTHORING.md`を読み、ページ追加前に配置チェックを行います。`setup-doc-skill.sh`のUpdateモードにも、新規作成か更新かの判断を含む配置チェックを追加しました。(0d162828, 947aa27f)

### バグ修正

- 生成プロジェクトのZFBを5.2.2系に固定しました。フォーム送信(ネイティブのエンコード、フォームの所属、組み込みプロパティを隠すコントロール、送信操作の状態)とSVG/xlinkのURLを文書のベースに対して解決するクライアントルーターの修正を取り込みます。フレームワークと履歴サーバーの指定もともに`^9.1.3`へ更新します。(3e7f4620)
- MCP機能を有効にした場合、Cloudflareデプロイのセクションは生成された`README.md`を置き換えず、末尾に追記されるようになりました。(0d162828, 947aa27f)

### その他の変更

- 生成するCloudflareプロジェクトのWranglerを4.158.0に固定し、リリース時の依存バージョン鮮度チェックに対応しました。(3e7f4620)
