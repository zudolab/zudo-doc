### バグ修正

- `@takazudo/zdtp`が、Design Token Panelを有効にしたときだけ生成プロジェクトに追加されるようになりました。従来はすべてのscaffoldで無条件の直接依存になっており、これが同リリースで修正した`@takazudo/zudo-doc`のバンドル不具合を生成プロジェクトが回避できていた理由でもあります。そのため、パネルを使わないプロジェクトも一度も使わないパッケージをインストールして抱え続けていました。上流の不具合が修正されたことに伴い、この依存は`designTokenPanel`に連動するようになりました。(a93ff2293)
- 6つの機能フラグの既定値がonになり、FEATURESカタログと一致しました: `--sidebar-resizer`、`--sidebar-toggle`、`--toc-toggle`、`--doc-history`、`--llms-txt`、`--asset-viewer`。フラグを明示せずに作成したscaffoldにはこれらの機能が含まれます。除外する場合は対応する`--no-`フラグを指定してください。(6d0d3bfb9)

### その他の変更

- 上記の変更と矛盾していたCLIリファレンスの表を修正しました。既定値の列をカタログと一致させ、これまで抜けていた`--[no-]asset-viewer`の行をカタログ上の位置に追加しています。パッケージのREADMEの機能一覧も同様に修正しました。(c908f7f9a, f006d4ada)
