### その他の変更

- 生成されるプロジェクトの `@takazudo/zudo-doc` のピンが `^5.26.4` になりました。新規に生成したプロジェクトでは、本リリースのモバイルドロワーに関する 2 件の修正 — Escape での閉じる操作とトグルへのフォーカス復帰、および開いた状態でバックドロップに覆われず X をクリックできること — がそのまま有効になります。
- デザイントークンパネルを有効にしたプロジェクトの `@takazudo/zdtp` のピンが `0.8.2` になりました。このリリースは依存関係の整理のみで、`0.8.1` との公開物の差分は `package.json` と `CHANGELOG.md` だけです。コードの変更はないため、既存プロジェクトでの設定変更は不要です。
