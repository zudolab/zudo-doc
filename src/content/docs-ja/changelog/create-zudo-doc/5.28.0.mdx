### その他の変更

- 生成されるプロジェクトのzfb、zfb-runtime、zfb-md-wasmを`2.21.1`に固定し、SSR、コレクションのフィルター処理、起動、ワークスペースの再読み込みの修正を取り込みます。デザイントークンパネルを有効にしたプロジェクトではzdtpを`0.8.5`に固定し、SPA遷移後に孤立した、または空になったパネルのルートを復旧するとともに、初回マウント時の開いた状態を保持します。設定の移行は不要です。 (6686f2da6, e82e57551, fafdcf7fc)
