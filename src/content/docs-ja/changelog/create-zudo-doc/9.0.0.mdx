リリース日: 2026-10-27

### 機能

- テーマパックの選択肢で Graphite を先頭、Classic を 2 番目に表示し、ライト/ダークのプロジェクトで Classic を選ぶと `themePack: "default"` を書き込みます。新しいプロジェクトはデフォルトで Graphite の見た目になります。(d8c2e5ae)

### その他の変更

- 生成されるプロジェクトは `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` 9.0.0、および zfb 5.1.5 系（`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm`、Cloudflare アダプター選択時は `zfb-adapter-cloudflare`）を固定するようになりました。(c63f8df0)
- MCP を有効にしたプロジェクトで Wrangler 4.153.0 を固定します。(185bdafe)
