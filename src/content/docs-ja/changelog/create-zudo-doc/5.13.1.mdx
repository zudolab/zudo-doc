リリース日: 2026-08-28

### バグ修正

- 検索機能を有効にしたプロジェクトに、使用されていない`minisearch`と`pagefind`の依存関係を追加しないようにしました。検索はzudo-doc自身が生成する検索ウィジェットのスクリプトが担っており、どちらのパッケージも読み込まれていませんでした。 (`7915fe55`)
- 検索機能の名称を「Pagefind search」から「Full-text search」へ変更しました（CLIのプロンプト、生成されるCLAUDE.md、READMEのフラグ一覧）。生成されるプロジェクトが実際には使用していない連携を説明していたためです。`search`という機能キーと`--[no-]search`フラグは変更していません。 (`7915fe55`)

### その他の変更

- 新規生成プロジェクトが使用するzfbパッケージ群を2.13.1へ更新しました。 (`c36fd4d0`)
