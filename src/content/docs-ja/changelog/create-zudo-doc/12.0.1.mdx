リリース日: 2026-11-14

### その他の変更

- `create-zudo-doc` 12.0.0 はタグ付けされましたが npm には公開されていません。Wrangler 4.162.0 のリリース後、公開時のスキャフォールドのピン鮮度チェックが Wrangler 4.161.0 のピンを拒否したためです。12.0.1 は `create-zudo-doc` で最初に公開される 12.x リリースです。11.0.0 からアップグレードする場合は 12.0.0 のリリースノートも参照してください。
- 新しく生成するプロジェクトは `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` を `^12.0.1` でピン留めします。
- MCP スキャフォールドは Wrangler 4.161.0 ではなく 4.162.0 をピン留めします。
