リリース日: 2026-10-24

### 破壊的変更

- 生成するプロジェクトが ZFB 5.0.1 系と zudo-doc 8.x を使うようになりました。既存プロジェクトでは ZFB 関連パッケージを一緒に更新してください。Node.js の下限は引き続き 24 です。

### その他の変更

- 初期化ツールと生成するプロジェクトで Node.js の上限を撤廃し、24 以降を受け入れるようにしました。CI で検証しているのは引き続き Node 24 LTS です。(d5336a24b)
- 生成する Cloudflare MCP プロジェクトの MCP SDK を 1.32.2 に更新しました。
