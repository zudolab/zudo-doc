### その他の変更

- 生成されるプロジェクトは `@takazudo/zudo-doc`・`@takazudo/zudo-doc-history-server` 8.1.1 と zfb 5.1.3 系を固定するようになりました。zfb 系は `@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` で、Cloudflare アダプター選択時は `zfb-adapter-cloudflare` も含みます。(62648582)
- デザイントークンパネルを有効にすると、生成されるプロジェクトは `@takazudo/zdtp` 0.8.7 を固定するようになりました。開いた直後の復帰処理中に閉じるボタンや Escape で閉じた状態が保たれ、ページ切り替えをまたいだ早いクリックも失われなくなります。(62648582)
