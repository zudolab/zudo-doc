### 機能

- 生成されるプロジェクトの `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` のバージョン指定を `^5.21.0` にしました。新規に生成したプロジェクトでも、`zfb.config.ts` を手で編集してホームページの `introMarkdown` や `sitemapHeading` を設定できます。CLI のオプションは追加していません。生成される設定はパッケージの既定値のままで、既定値との差分だけを書き出す形を維持しています。(`77ed96b3f`)
