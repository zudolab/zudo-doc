### その他の変更

- 生成されるプロジェクトの `package.json` が、`@takazudo/zfb`・`@takazudo/zfb-runtime`・`@takazudo/zfb-md-wasm` を `2.16.0` に、デザイントークンパネル機能を有効にした場合の `@takazudo/zdtp` を `0.5.2` にピン留めするようになりました (`47c149385`)。いずれの上流リリースも新規スキャフォールドにそのまま適用できます。zfb 2.16.0は書き出した直後のesbuildバイナリを初回実行する際の `ETXTBSY` クラッシュを修正するもので、zdtp 0.5.2は追加のみの変更です。公開API・エクスポート・設定のデフォルト値・エンジン要件はいずれも変わらず、新規スキャフォールドに移行作業は不要です。
