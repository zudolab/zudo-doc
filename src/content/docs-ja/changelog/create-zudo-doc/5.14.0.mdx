リリース日: 2026-08-31

### 機能

- `--asset-viewer` 機能フラグを追加しました。生成プロジェクトの `zfb.config.ts` に `assetViewer: true` を出力し、ホスト側のルートスタブや追加のテンプレートファイルを作成せずに、`public/assets/` 配下のファイルをパッケージが提供するビューアーで表示できます。 (`45dc50cdb`)
- ドキュメント履歴を使う生成プロジェクトの並行開発サーバーを、パッケージが提供する `run-parallel` コマンドで実行するようにしました。`npm-run-all2` を削除し、未対応の末尾引数を黙って無視せずエラーとして報告します。 (`9402ff157`, `3ebfa6e9c`)

### バグ修正

- 生成されるリンクチェッカーが、有効な引用符なしHTML属性を認識し、文字参照をデコードし、パーセントエンコードされたルートを解決し、シリアライズ済みマークアップの誤検出を避けるようにしました。 (`db9a07018`)

### その他の変更

- 新しく生成されるプロジェクトをzfb 2.14.0パッケージファミリーと `@takazudo/zdtp` 0.4.14へ更新しました。 (`dbe8553c7`, `038870c94`)
