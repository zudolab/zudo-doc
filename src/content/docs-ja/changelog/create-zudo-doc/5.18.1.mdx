リリース日: 2026-09-06

### その他の変更

- 生成されるプロジェクトの`@takazudo/zdtp`のピンを`0.5.1`に更新しました（従来は`0.5.0`）。新規に生成したプロジェクトでは、zdtpのパネル幅・ヘッダーのはみ出し・ドキュメント適合性に関する修正に加え、クライアントサイドナビゲーションをまたいで複数パネルのカスケード位置を安定させる`spawn-ordinal`ストレージキーが利用できます。(4a72db50d)
- 生成されるプロジェクトは`@takazudo/zudo-doc@^5.18.1`を通じてページ読み込みスピナーのコントラスト修正を継承します。新しい`--color-page-loading-spinner`トークンとreduced-motionの変更については、同パッケージの5.18.1のリリースノートを参照してください。(4fa1651b2)
