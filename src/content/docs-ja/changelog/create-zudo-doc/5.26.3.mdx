リリース日: 2026-09-21

### その他の変更

- 生成されるプロジェクトが `@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-md-wasm` の `2.20.1` を固定するようになりました。2.20.1 はリリースメタデータのみの更新で、パッケージ固有の変更を報告しているパッケージはなく、公開された tarball の差分は各パッケージ自身のバージョンフィールドとプラットフォームバイナリの固定指定に限られます。既存プロジェクトの設定移行は不要です。(07d700356)
- デザイントークンパネルを有効にした生成プロジェクトが `@takazudo/zdtp` の `0.8.1` を固定するようになりました。0.8.1 では、トークンマニフェストの `modes` 行をライト・ダークそれぞれ個別に編集できるようになり（ペアは `light-dark()` としてコミットされます）、Palette Check ビューでは `readonly` 行が表示専用のまま維持され、`item.default` と等しい保存済みオーバーライドがマニフェストのペアより優先されます。`@takazudo/zudo-doc` の peer range はすでにこのバージョンを許容していたため、既存プロジェクトの設定移行は不要です。
