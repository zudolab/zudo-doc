- API、CLI、プリセット、プロンプト、スキャフォールド出力、生成ガイダンスで共通の順序付きロケールプラン契約を追加し、新規プロジェクトでサポート対象の任意のロケールセットを選択・出力できるようにしました。 (`10e34ca0`, `5a990248`, `c9543772`)
