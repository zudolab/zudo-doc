リリース日: 2026-10-15

### 破壊的変更

- 生成するプロジェクトと初期化ツールの実行環境を Node.js 24 LTS（`>=24 <25`）に変更し、Node 22 のサポートを終了します。生成される `package.json` は `engines.node: ">=24 <25"` を宣言します。(98c94df73, 2001f82d0)

### その他の変更

- 新規プロジェクトで `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` を `^7.0.0` に固定します。
- 新規プロジェクトで公開済みの zfb 4.5.2 系を固定します。MCP を有効にした場合の Cloudflare アダプターと Wrangler 4.151.0 も含みます。(e5b7de457, d5e0d7078)
