### 機能

- 生成するプロジェクトの `@takazudo/zudo-doc` と `@takazudo/zudo-doc-history-server` のバージョン指定を `^5.22.0` に更新しました。`zfb.config.ts` の `docMetainfoFields` と `docHistoryUi` を編集すると、表示するメタ情報を選択し、履歴ビューアーを表示せずに日付を維持できます。生成される設定はパッケージの既定値を維持し、新しい CLI フラグは追加していません。(`06044fa30`)
