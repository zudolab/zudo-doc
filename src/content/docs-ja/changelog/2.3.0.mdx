リリース日: 2026-07-03

### 機能

- **ホスト chrome バインディングの継ぎ目** — ホストプロジェクトがレイアウトコードを
  フォークせずにフレームワークの chrome へマークアップや呼び出し可能な処理を注入できる
  新しい拡張ポイントを追加しました。`chromeBindingsModule` によるホスト呼び出しチャネル
  (ffedd8f4, #2501)、`docContentHeaderExtras` と `homeExtras` のバインディングスロット
  (8e553706, #2500)、`./home-page` サブパスエクスポート経由で公開され独自の extras 継ぎ目を
  持つ `createHomePageView` ファクトリ (20d728e8 / 34dfa5e7, #2502) を含みます。`HomePageView`
  はホスト chrome アダプタから再エクスポートされ、パッケージ・ショーケース・テンプレートの
  ホームルートで採用されました (40f88971 / 2f371ba6 / 3b9cea8d, #2503)。
- **アクセシビリティのコントラスト監査ツール** — 全カラーペア行列を検査するコントラスト
  ガードを追加しました。`--suggest` モードでは WCAG のしきい値をクリアするための OKLCH
  調整を提案します (0f9668ad / 29d585e5, #2490, #2492)。

### バグ修正

- **doc-history:** リネームチェーンのシールをチェーンの物理パスにスコープし、無関係な
  ファイルが履歴を共有しないようにしました (2520270b, #2517)。
- **home-page:** デフォルトロケールで `categoryMetaDir` を尊重するようにしました
  (28da87c4, #2519)。
- **chrome バインディング:** 空の `chromeBindingsModule` に対して明示的なエラーを出し、
  ディレクトリ値のパスをガードするようにしました (8cea6c2b / 86c35b5d, #2518)。
- **アクセシビリティ:** ダークプリセットとライトスキーム全体のコントラスト不合格を解消し、
  261 のマージナルなペアをしきい値+0.1 の余裕まで再調整し、muted/accent トークンを実際に
  レンダリングされた背景上で監査しました (57a16896 / d518d546 / 87a1d6b1, #2493, #2497, #2510)。
- **e2e:** `wrangler dev` 下の競合を修正するため、フィクスチャプレビューごとに workerd
  インスペクタポートをランダム化し (fe9eceb6, #2084)、フィクスチャの wrangler 設定を
  Workers static-assets へ移行しました (a1c2f330)。

### その他の変更

- **doc-history:** preBuild メタ生成を単一パスの `--name-status` ウォークにしました
  (07a98c11, #2517)。
- **home-page:** `prepareHomeData` を抽出し、6 つのアダプタを縮小しました (c9c4e765, #2519)。
- **依存関係:** zfb ファミリを `0.1.0-next.75` へ更新しました (9e305f5d, #2511)。
- **ドキュメント:** ホスト chrome バインディングの継ぎ目を文書化し (EN + JA)、
  `color-scheme-a11y` プロジェクトスキルを追加しました (31a69ce5 / 33c04519)。
