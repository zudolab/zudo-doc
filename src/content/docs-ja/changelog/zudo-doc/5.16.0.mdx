リリース日: 2026-09-02

### 機能

- `transclude`によるオプトインのMarkdown/MDXトランスクルージョンと、検索、llms.txt、サイトマップ出力を個別に制御できる`assetViewerIndexing`を追加しました。 (`8145aae41`)
- 生成されたアセットビューワーページをサイトマップに列挙し、検索およびllms出力へインデックスできるようにしました。ロケール、ベースパス、除外設定に対応し、コンテンツ抽出量を制限します。 (`5da03612e`, `b48009d7e`, `3de313585`, `76b90bc48`)

### バグ修正

- 改行を含まない長いタイトルが、ドキュメント、ホーム、アセット、バージョン、タグの各ページで折り返されるようにしました。 (`f21c6b73d`)
- 大きなファイルからアセット検索の抜粋を生成する際、読み取り量を制限するようにしました。 (`6c81a13b3`)
- llms出力内のアセットリンクが、設定された`siteUrl`を反映するようにしました。 (`67482a1d5`)

### その他の変更

- 任意のピア依存である`@takazudo/zudo-doc-history-server`の下限を、公開済みの5.15.0へ引き上げました。 (`01bd83bc7`)
