リリース日: 2026-09-27

### 機能

- 検索対象となるページ本文の上限を300文字から3000文字に拡大し、長いページの冒頭以外も検索できるようになりました。`searchMaxBodyLength`に正の整数を指定すると上限を変更できます。検索結果の抜粋の表示長は変わりません。 (332a6184b)

### バグ修正

- 目次とリンク検査の見出し抽出で、複数行のJSX式、コメント、引用符付き属性、テンプレートリテラルのprops内にある見出し風のテキストを除外し、JSXの子要素内の見出しは維持するようにしました。複数行のインラインコードによってJSXの判定が乱れる問題も修正しました。 (b85fe3469, 99ad4252b)
- モバイルドロワーのAppearanceメニューでEscapeを押すと、メニューだけが閉じてトリガーにフォーカスが戻ります。もう一度Escapeを押すとドロワーが閉じ、ハンバーガーボタンにフォーカスが戻ります。 (66359d27c)

### その他の変更

- zfb、zfb-runtime、zfb-md-wasmのpeer依存の下限を`^2.21.1`に更新しました。SSRでのPreactランタイムの一本化、コレクションのincludeフィルター処理、起動速度、ワークスペースパッケージのステージングと再読み込みの修正を取り込みます。設定の移行は不要です。 (6686f2da6, e82e57551)
