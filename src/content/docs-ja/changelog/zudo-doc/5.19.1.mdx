リリース日: 2026-09-08

### その他の変更

- zfbのピア依存関係および開発依存関係の一式を2.16.0へ更新しました (`47c149385`)。上流のリリースにはバグ修正が1件含まれます。zfbのesbuildバージョンゲートの起動処理 (`ensure_binary_verified`) が、素の `.output()` ではなくzfb-buildの既存のリトライループを介して `ETXTBSY` をリトライするようになり、パッケージ版のzfbが一時ディレクトリへ書き出した直後のバイナリを初回実行する際に `Text file busy (os error 26)` でビルドが落ちることがなくなりました。`@takazudo/zfb-md-wasm` はREADMEのみの変更で、同梱される成果物はすべて2.15.1と同じバイトサイズを維持しており、公開API・エクスポート・設定のデフォルト値・エンジン要件はいずれも変わっていません。
- `@takazudo/zdtp` のピア依存関係の下限を `^0.5.2` へ引き上げました (`47c149385`)。上流のリリースは本パッケージにとって追加のみの変更です。ヘッダーアクションに安定した `data-zdtp-action` 属性が追加され、ポップオーバーとヘッダー項目の対応付けが表示ラベルではなくそのアクションIDを使うよう修正されました。ストレージキーや設定形状の移行はなく、ベンダリングしているデザイントークンパネル定数のミラーは実際の `@takazudo/zdtp/constants` に対して適合したままです。
