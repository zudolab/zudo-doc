リリース日: 2026-10-15

### 破壊的変更

- 対応する Node.js の実行環境を現在の本番向け LTS 系列である Node 24（`>=24 <25`）に変更し、Node 22 のサポートを終了します。(98c94df73)
- GHSA-238p-pmpm-9mq7 の修正に合わせ、オプショナルな KaTeX ピアの下限を `^0.18.2 || ^0.19.0` に引き上げ、0.16.x のサポートを終了します。内部の色セレクターを更新し、サーバー側レンダリング、エラー表示、KaTeX なしの数式無効ビルドを保ちます。数式を使うホストは対応バージョンとローカル CSS のインポートが必要です。(9ee3950c9)
- 公開済みの zfb 4.5.2 系を必須とし、`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` の peer 下限を `^4.5.0` から `^4.5.2` に引き上げます。開発時の `public/assets/` の即時配信、明示的な MDX テーブルと 1 行のコンパクトなテーブルの修正、ルート公開後にのみ表示される `zfb dev` の準備完了表示を取り込みます。zfb 系（使用時は `zfb-adapter-cloudflare` も）をまとめて更新してください。(e5b7de457, d5e0d7078)
- このメジャーリリースに合わせ、`@takazudo/zudo-doc-history-server` の peer 下限を `^6.0.0` から `^7.0.0` に引き上げます。

### バグ修正

- ダイナミックページトランジション中、遷移先のマークアップに置き換わる場合もヘッダーを静止させ、同じナビゲーションカテゴリ・言語・バージョン・ツリー内ではデスクトップサイドバーも静止させます。遷移先の最新の内容と既存のサイドバーの状態管理を維持し、変化する記事と目次は引き続きアニメーションします。サイドバーの表示・非表示の遷移は `hide_sidebar` を使うページにも対応します。読み込み中の表示はヘッダーやデスクトップサイドバーを暗くせずにコンテンツ領域を覆い、ページのアニメーションには混ざりません。コンテンツの差し替えまたはナビゲーションの中止時に解除します。(ae7152ad5, 6abeadf5f, 479309f1f)
- 通常のドキュメント本文やナビゲーションのラベルが、狭い幅で横にはみ出さずに折り返すようになりました（コンテンツに `overflow-wrap: anywhere`）。整形済みのコードは引き続きその場でスクロールします。(648e38da8)
