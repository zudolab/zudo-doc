リリース日: 2026-10-12

### 機能

- サイト名のリンクだけをナビゲーションや操作ボタンとは別に設定できる`--zdc-header-logo-font`と`--zdc-header-logo-weight`を追加しました。同梱テーマパックは従来の既定値を保ちつつ両トークンを反映します（[#4533](https://github.com/zudolab/zudo-doc/issues/4533)）。(96243bc6)

### バグ修正

- `defineChromeBindings({ mdxExtras })` が、独自の必須型付きprops（例: `(props: { html: string }) => Child`）を持つMDXコンポーネントを再び受け付けるようになりました。6.0.0で発生したTS2322の退行の修正です。エントリーは引き続き描画可能な`Child`を返すコンポーネントである必要があり、固定のchromeスロットは呼び出し側のprops検査を維持します（[#4530](https://github.com/zudolab/zudo-doc/issues/4530)）。(bd090491)
- ネイティブのサイドバーアイランド（`SidebarToggle`、`SidebarTree`）がページのdescriptionをクライアントペイロードにシリアライズしなくなり、各ページのハイドレーションデータが小さくなりました。カスタムのアイランドホスト向けに、同じ射影を行う`toSidebarClientData(nodes, navigation?)`ヘルパーを`@takazudo/zudo-doc/sidebar`に追加しました。カスタムの`sidebarNodes`配列は参照を渡すのではなくコピーされるようになりました（[#4536](https://github.com/zudolab/zudo-doc/issues/4536)）。(a1e01aad)
