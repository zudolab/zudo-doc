リリース日: 2026-06-06

HTML Preview コンポーネントのハイドレーション後レイアウト（Astro から zfb への移行リグレッション）を、既存のスキャフォールドをアップグレード後も壊さない後方互換な方法で修正した、ピンポイントなプレリリースです。

### バグ修正

- **HTML Preview が正しい縦積みレイアウトでハイドレーションされるようになりました。** `/docs/components/html-preview/` で、ハイドレーション後にプレビューとコードのセクションがタイトルバー内に再ネストされ、レイアウトが横並びに崩れていました。原因はアイランドの二重ラップです。素の（bare な）ハイドレーション対象が外側ラッパーの `displayName` を持っていたため、SSG のアイランドマーカーが自己ラップするエクスポートに解決され、クライアントが 1 階層ずれてハイドレーションしていました（Toc/MobileToc/Sidebar で #1355 として修正されたものと同じ種類のバグです）。素の内部コンポーネントが独自の名前とマーカー（`HtmlPreviewWrapperInner`）を持つようにし、`HtmlPreviewWrapper` は公開用の `<Island when="visible">` エクスポートとして維持しました。これによりホスト・テンプレート・既存の下流スキャフォールドは呼び出し側の変更なしで動作し続け、正しい縦積み（タイトルバー / プレビュー / コード）でハイドレーションされるようになりました（#1925）。
