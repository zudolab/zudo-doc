リリース日: 2026-09-09

### 機能

- ホームページに、短い Markdown の導入文を表示できるようにしました。`home.introMarkdown` に指定した Markdown が `/` のホーム識別情報の下に表示され、デフォルト以外のロケールでは `LocaleConfig.introMarkdown` で上書きできます。空の場合はこれまでのレイアウトのままなので、既存サイトへの影響はありません。(`77ed96b3f`, `8e10ecbc1`)
- ホームのサイトマップ見出しを変更できる `home.sitemapHeading` と `LocaleConfig.sitemapHeading` を追加しました。空文字列を指定すると、翻訳済みの既定の見出しに戻ります。(`77ed96b3f`)

### バグ修正

- ホームのサイトマップとタグの見出しを共通のコンポーネントで描画するようにしました。サイトマップの見出しだけが内側の狭い段に寄っていた問題を修正し、どちらも全幅のコンテンツ幅に揃うようにしています。(`849e04a57`)
