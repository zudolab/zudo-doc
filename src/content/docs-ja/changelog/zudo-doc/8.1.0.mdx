リリース日: 2026-10-25

### 機能

- オプトインの `headerBrand` 設定（`false | { icon: string }`、デフォルト `false`）を追加しました。ヘッダーのサイト名の前に、文字色で塗られる（CSS マスク）装飾用の正方形アイコンを表示します。`/` で始まるパスにはサイトの `base` が 1 回だけ付与され、それ以外の URL はそのまま使われます。`icon` が空または未指定（あるいは `true`）の場合は設定解決時にエラーになります。サイト名はリンクのアクセシブルネームのままで、長い名前は引き続き省略記号で切り詰められ、アイコン設定中はテーマパックの先頭エンブレムが非表示になります。 (fb3358ca)
- ホームのヒーロー `<h1>` に、サイト名のスタイル用フックとして `data-zd-site-name` 属性を追加しました。 (fb3358ca)

### バグ修正

- ダイナミックページトランジション有効時に、フッターのリンク（または永続化されたクロム内のフォーカス中のリンク）から移動すると、現行の Chromium でもフッター付近に留まらず移動先ページの先頭で終わるようになりました。パッケージ所有のインラインの head スクリプトが、永続化された DOM の移動後かつルーターが先頭・ハッシュ・履歴のスクロールを適用する前に、ブラウザが保留したフォーカスによるスクロールを確定させます。フォーカス、永続化、トランジション、スクロール復元の挙動は変わりません。Content Security Policy でインラインスクリプトのハッシュを固定しているサイトは、新しいスクリプトのハッシュを追加してください。 (524a440f)
- `SiteTreeNav` のラベルが、破線の枝の終端から常に少し間隔を空けて始まるようになりました。以前は広いビューポートで、ホームページの 2 倍幅の枝がラベルの文字に食い込んでいました。 (3e6e720f)

### その他の変更

- zfb 5.1.2 が必須になり、`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` の peer 下限を `^5.0.1` から `^5.1.2` に引き上げます。zfb 5.1.0 には islands のビルドガードが追加され、出力された islands チャンクが islands エントリーを import している場合にビルドが失敗するようになりました（本番ではその import が 404 になるため）。zfb 5.1.1 は Windows 環境（ベアパッケージのサブパス解決と `pnpm.cmd` の起動）と、シンボリックリンク経由のパスでビルドするプロジェクト向けの修正リリースです。zfb 5.1.2 はネイティブエンジンと WASM バイナリを再ビルドしたリリースで、JavaScript API に変更はありません。それ以外のチャンク分割は変わりません。このリリースと合わせて zfb 系（使用時は `zfb-adapter-cloudflare` も）を 5.1.2 にまとめて更新してください。 (6eef9416, 44d7684b)
