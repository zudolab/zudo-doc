リリース日: 2026-06-17

### 機能

- Mermaid 図に拡大ボタンを追加し、大きなフローチャートを確認するためのズーム/パンダイアログを開けるようにしました（#2186, ad08b5b5）

### バグ修正

- SPA のソフトナビゲーション後も Mermaid 図が描画され続けるようにし、クライアントサイドのルート変更後に図が消えなくなりました（#2181, a37b4907）
- ズーム/パンダイアログ内で拡大した Mermaid 図がはみ出さないようにし、エッジラベルの見切れを解消しました（#2193, 63e2f82f）
- `llms.txt` 出力から JSX/MDX のブロックコメントを除去し、生成テキストに生のコメントマーカーが混入しないようにしました（#2192, edd361e4）
- `create-zudo-doc`: 生成される `.gitignore` の doc-skill ブロックを `skillSymlinker`/`i18n` フィーチャーでゲートし、barebone スキャフォールドでは出力しないようにしました（#2182, 1dc8de35）
- `create-zudo-doc`: 生成される doc-lookup スキルを確定的に gitignore するようにしました（#2173, 10d0b183）
- `create-zudo-doc`: `imageEnlarge` フィーチャーの重複した settings インポートを削除しました（#2172, ba66300f）

### その他の変更

- `.zd-content` のコンテンツタイポグラフィスタイルシートを `@takazudo/zudo-doc` から `content.css` として配信するようにし、ホストの `global.css` と生成テンプレートの両方から `@import` する形にして、両者間のコピー差分を解消しました（#2196, 44eb0dfe）
- `@takazudo/zfb` を 0.1.0-next.49 → 0.1.0-next.51 にバンプしました（#2171, d91aae48）
