リリース日: 2026-08-20

### 機能

- ショーケースと生成プロジェクトのリンクチェッカーに厳密なアンカー検証を追加し、生成サイトでもソースを基準に検証できるようにしました。 (`b50bd9aac`, `59127e7fe`)
- npmでまだ公開されていないファーストパーティーパッケージをリリース用スキャフォールドが参照しないよう、公開済みバージョンのガードを追加しました。 (`4bdc37132`, `8c234c08e`)
- ejectしたヘッダーにナビゲーションオーバーフローの完全な再生成手段を同梱し、CSP用の安定したバイト列を維持しながらローカルのナビゲーション動作とクラストークンをカスタマイズできるようにしました。 (`1b3d501c3`, `721ff37d3`)

### バグ修正

- `data-zd-props-preserve`でネストしたアイランドのprops保持を明示できるようにし、オプトアウトしたアイランドがクライアントナビゲーション時にprops更新や再マウントフラグを受け取らないようにしました。 (`e75cff084`)

### その他の変更

- `docTags`が未選択の場合に`true`と`false`のどちらの設定フィールドも出力されないことを確認する回帰テストを強化しました。 (`37dec787c`)
- パッケージ、ショーケース、生成スキャフォールドの`@takazudo/zdtp`を0.4.12へ更新しました。
