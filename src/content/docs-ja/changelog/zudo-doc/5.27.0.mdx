リリース日: 2026-09-24

### 機能

- ライト・ダーク・システムを選べる、アクセシブルな外観メニューを追加しました。システム設定の変更に追従し、選択した設定はページ移動後も保持されます (5bb3d2175, d2146b6e0)。

### バグ修正

- ヘッダーのアイコンを 40 px の操作領域でまとめ、アイコン間の追加の余白をなくし、他のコントロールとの間に 12 px の余白を設けました。外観メニューを閉じた後のキーボードフォーカスもトリガーに戻ります (4c718aa02)。
- 外観メニューがデザイントークンパネルの上に表示され、画面内に収まるようにしました (1773a3a21)。
- 見出しにエスケープされた記号やコードスパンがある場合の見出し ID と目次リンクを修正しました (59d47f68a)。

### その他の変更

- 対応する zfb ツールチェーンの最小 peer バージョンを 2.20.2 に引き上げました (e22acafdf)。
