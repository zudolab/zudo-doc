リリース日: 2026-09-23

### バグ修正

- pnpm ワークスペース内のネストされたプロジェクトで、パッケージ提供ルートの挿入に失敗する問題を修正しました。公開済みのルートソースをプロジェクトルートに配置し、ビルド用のシャドーツリーから生成された 404、robots、docs ルートを解決できるようにしました (848264b9c)。5.26.4 以前でスキャフォールドしたプロジェクトは `.gitignore` に `.zudo-doc/` を追加してください。ビルドが配置済みのルートソースを `.zudo-doc/routes-src/` に書き込むようになったため、無視エントリがないと `git status` が未追跡ディレクトリとして表示します。新規スキャフォールドは既にこれを無視しています。詳細は `create-zudo-doc` の変更履歴を参照してください。
