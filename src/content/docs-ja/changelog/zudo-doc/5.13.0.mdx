リリース日: 2026-08-27

### 機能

- ブラウザーで安全に利用できるルートコンテキストのペイロード型、`createRouteContextPayload()`、テーマパックレジストリービルダーを追加し、ホストアプリケーションがzfbのルートランタイム外でもパッケージ標準のクロームを描画できるようにしました。 (`f25c76b9`, `e5db342e`, `b7221d01`)
- スタイルシート対応状況の明示的なメタデータと実行時検証を備えたテーマカタログスキーマv2を公開しました。 (`169c9103`)
- ブラウザーでそのまま利用できる決定的な`@takazudo/zudo-doc/compiled.css`エクスポートを追加し、zfbのスタンドアロンCSSコンパイラーで生成するようにしました。 (`3258a445`, `211b4e7b`)
- ハイドレーションが完了するまでテーマコントロールをアクセシブルなまま操作不可にし、早期に操作できる直接利用者向けに`pendingUntilHydrated={false}`を用意しました。 (`2c71e483`, `b2faceb7`)

### バグ修正

- 永続化されたネストアイランドのprops更新を、ルーターの中断時にも安全なコミット境界に合わせ、戻るナビゲーションの競合時に古いナビゲーションデータが現在のページへ反映される問題を防ぎました。 (`4a0ffce6`)

### その他の変更

- zfbのpeer package群を2.12.0へ更新しました。 (`9cf3fd4b`)
