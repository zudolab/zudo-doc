リリース日: 2026-11-19

### その他の変更

- ZFB 7.1.0 ファミリ（`^7.1.0`）が必須になりました。7.1.0 は `@takazudo/zfb-linux-arm64-gnu` を再び公開するため、Linux arm64 の npm インストールには 7.0.0 で省かれていた CLI と CSS のキャリアが入ります。Linux x64、macOS、Windows の npm インストールは変わりません。
- ワークスペースは `@takazudo/zdtp` 0.9.9 を使います。peer 下限は `^0.5.2 || ^0.6.0 || ^0.7.0 || ^0.8.0 || ^0.9.0` のままで、0.9.9 を受け入れます。0.9.9 の zfb peer は変わらず、zfb 7.1.0 に対してビルドされています。
