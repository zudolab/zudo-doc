リリース日: 2026-08-20

### 機能

- `NAV_OVERFLOW_SCRIPT` を、パッケージビルド時に生成しコミットされたリテラルとして出荷するようにしました(ドリフトガード付き)。バイト列がコンシューマ側のバンドラーに依存しなくなり、公開する CSP インラインスクリプトハッシュ 1 つですべてのレンダリングをカバーできます。凍結後の出力は従来のレンダリング時組み立てとバイト単位で同一のため、このリリースでハッシュは変わりません (93865aac)
- `check:nav-overflow-drift` ガードを b4push(全 29 ステップ中のステップ 14)、CI、b4push/CI パリティマニフェスト、`prepack` に登録しました。スクリプトのソースが変更されると、コンシューマの CSP ハッシュが静かにずれる代わりに大きく失敗します (a9440c2e)

### バグ修正

- 同一ロケールでセクションをまたぐソフトナビゲーション後に、モバイルドロワーが古いセクションツリーとアクティブマーカーを保持し続ける問題を修正しました。永続化要素内のネストされたアイランドの `data-props` を `zfb:before-swap` の時点で更新するようにし、zfb のトップレベル永続アイランド更新を一般化しています。ロケール切り替えの挙動とヘッダーの永続化は変わりません (9dd1b77c)
- スワップをまたいで dynamic import が進行中のアイランドも、更新後の props で再マウントされるようにしました(変更時に `data-zfb-island-remount` を設定)。ドロワーがナビゲーション前のスナップショットからマウントされるレースを解消しています (797e9a8c)
- `prepack` が `check:search-widget-drift` でもゲートされるようになり、ドリフトしたツリーから CSP を壊す `SEARCH_WIDGET_SCRIPT` のバイト列が公開されることがなくなりました (5103feb3)

### その他の変更

- モバイルでのセクションをまたぐソフトナビゲーションに対するドロワーの e2e リグレッションスペックを新規追加しました(smoke フィクスチャ、共有ドロワーヘルパー付き) (5ac8f536)
- route-injection パリティスナップショットを、原因の完全な帰属記録付きで再ベースラインしました。今後説明のつかないハッシュ移動があった場合は、再ピンではなくライブな非決定性として診断すべきことをファイル内に明記しています (7a607cd5)
- テストのハードニングに伴う再階層化にテストドキュメントを追従させました。fast/slow レーンの明確化と、再階層化後のテスト数の修正を含みます (07fff398)
