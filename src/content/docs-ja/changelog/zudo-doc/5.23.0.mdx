リリース日: 2026-09-13

### 機能

- ビルド済み HTML 内のローカル画像・メディア参照切れを厳密に検証する `zudo-doc check images` を追加しました。 (90e513fa8)
- アセットスキャンを相対 `src`、`srcset`、メディア要素、SVG 参照、`<base href>`、ディレクトリ外参照を防ぐ安全なパス解決に対応させました。 (9f1cf6e31)

### バグ修正

- 生成される Claude リソースの frontmatter を、従来の YAML スカラー別名を含めて MDX フォーマッターで安定する形式にしました。 (9165c0547, db90c9685)
- 修飾名付き SVG `xlink:href`、pnpm の引数区切り、空のベース URL、ページパス内のリテラルなパーセント記号に対応しました。 (48b0aa781, 994e6aec3, c9b772b76)
