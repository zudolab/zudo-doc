リリース日: 2026-07-22

### 機能

- Theme Batch 5 として academia、bauhaus、blueprint、botanica、eink、riso、sakura、scandi、tidepool、timberline の10個の新しいテーマパックを追加し、カタログを31パックに拡張しました。それぞれ admonition・コード・サイドバーを完全にカバーし、レンダリング済みの WCAG コントラスト監査済みです (29bb3497f, 12665cdf1)
- 新しい `logo` 設定により、デフォルトでホームヒーローに自動生成ロゴを表示するようにしました。あわせて、ロゴのマークアップを完全に自前管理できる `zudo-doc eject logo` CLI サブコマンドを追加しました (a2ba5188a, 3cedbee04)
- `scripts/theme-a11y-audit.ts` を追加し、パックごとのレンダリング済みコントラスト監査ツールをナイトリー試験に組み込み、テーマ開発者向けにドキュメント化しました (4c969cd4a, 8ed913f9d)
- トップページの Tags セクションにタグチップを表示するようにし、ホームヒーローに `heroLink` プロップとインライン extras 行を追加しました (55be502c2, fc865e6be)
- ヘッダー・サイドバー・オーバーフロードロップダウン・doc-pager の非アクティブなナビ要素が、ホバー/フォーカス時に一貫してアクセントカラーになるようにし、ヘッダーナビのクラストークンを単一の情報源に統一しました (fafecc154, 274a8641f)

### バグ修正

- 既存5パックにわたるレンダリング済み a11y 監査の指摘10件を解消し、blueprint/sakura/tidepool の追加コントラスト修正と、深いレビューで見つかった5件の指摘も対応しました (b694708dc, 2c2dcc858, 12f7964f9)
- テーマ CLI の設定スキャンで `\uXXXX`、`\u{...}`、`\xXX` のエスケープを正しくデコードするようにしました (2e58e3dc0)
- デフォルトのタイトル罫線リセットを、テーマパック自身がタイトルスタイルを所有しているページのみに適用するようにし、カスタムパックのタイトルが二重罫線にならないようにしました (9043b9439)
- Doc History のアンカーが、実際に生成される見出しスラッグを指すよう修正しました (9e3e62655)

### その他の変更

- route-injection パリティテストの正規化 HTML sha256 スナップショットを今サイクル中に2回再ベースラインし、変更されたすべてのバイトを対応するマージ済み PR に紐付けました (5e46831d4, 4fd642c3b)
- `@takazudo/zfb` ファミリーを `0.1.0-next.90` に更新しました
- logo/eject-logo 機能、Theme Gallery（31パック）、ホバー時アクセントカラーのインタラクティブカラールールについて、英語・日本語ドキュメントを拡充しました
