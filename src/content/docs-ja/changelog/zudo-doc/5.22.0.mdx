リリース日: 2026-09-11

### 機能

- ドキュメントページに表示するメタ情報を選択できる `docMetainfoFields` を追加しました。既定では全項目を表示し、空の配列ではすべて非表示になります。`["updated"]` を指定すると、作成日と整形後の日付が同じ場合でも更新日を表示します。(`06044fa30`, `3832e08af`)
- `docHistoryUi: false` を追加しました。Git から生成するメタ情報を維持しながら、履歴ビューアー、履歴 JSON の生成、開発用プロキシを無効にできます。設定済みのソース表示リンクは引き続き利用できます。(`84cd63af5`)
- ビルド後にサイト絶対パスの `<img src>` が参照するファイルの存在を検査する機能を追加しました。既存の `onBrokenMarkdownLinks` 設定で重大度を指定できます。(`9cc259d65`)

### バグ修正

- ミラーリングした Claude のコマンド・エージェントと、Claude/Codex 共通のスキルで、出力されないファイルへのリポジトリ相対リンクをラベルのみで表示するようにしました。コード例と、スキル本文から出力済みサブページへのリンクは維持します。(`bb6d0390c`)
