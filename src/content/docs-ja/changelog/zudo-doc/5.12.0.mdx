リリース日: 2026-08-23

### 機能

- ノートトレイのカードを、カード全体をリンクにしながらタグリンクを独立して操作でき、広い画面ではローカライズされた日付スタンプを表示するレスポンシブなsubgridレイアウトへ刷新しました。 (`3b0f9301`)
- 月別ノートトレイのタイムラインに、アクセシブルな日番号マーカーを追加しました。 (`2d1efb7d`)

### バグ修正

- 番号付きノートトレイのインデックス行全体をクリック可能にし、ホバー時とキーボードフォーカス時の枠表示を統一しました。 (`6d729e0a`)
- サイトツリーに表示するノートトレイのメタデータを作成日のみに限定し、更新日を表示しないようにしました。 (`98283c9c`)
- タグ付きカードの枠をsubgridの先頭行に固定し、枠線がカード内容からずれないようにしました。 (`b33201e5`)
