リリース日: 2026-08-23

### 機能

- `siteTreeNavIgnore`設定を追加し、ドキュメントへのアクセスを維持したまま、指定したサイトツリーのカテゴリーをサイドバーとホームページのナビゲーションから除外できるようにしました。 (`2d1aa78f`)

### バグ修正

- グループ化されたノートトレイの子項目を、対応する展開レイアウトと同じ深いインデントに揃えました。 (`5bbf365f`)

### その他の変更

- zfbパッケージ群を2.10.0へ更新し、`siteTreeNavIgnore`と日付frontmatterを引用符で囲むガイダンスを日英で追加しました。 (`acaa01cf`, `3f15cc2f`, `c484754b`)
