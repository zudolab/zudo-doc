リリース日: 2026-10-14

### 機能

- 任意の `SidebarDefinition.scopeRoot?: "configured" | "editorial"` を追加しました（既定は `"editorial"` で、従来の動作は変わりません）。`"configured"` は、ツリーを広げる操作、枝のフォーカス、復元、経路の再調整が到達できる上限を、作者が定義したフォレストにします。空の `items` はそのカテゴリで絞り込んだツリーで止まり、`autogenerated` のディレクトリが 1 つだけのときはそのディレクトリで止まり、明示したリストはそのリストで止まります。`initialPath` は最初の表示と復元時の基準のままです。上限に達すると範囲ツールバーは出ません。未対応の値はビルドを失敗させます。定義を省略した項目と配列は editorial のままです。(418b2f29c)

### バグ修正

- 共有の `tsconfig.base.json` は `baseUrl` を設定しなくなりました。TypeScript 7 は、これを継承するすべてのプロジェクトで `baseUrl` を TS5102 として拒否します。継承した `baseUrl` に頼って `paths` の値を書いていたプロジェクトは、明示的な相対パス（例：`"@/*": ["./src/*"]`）にしてください。TypeScript 5.9 と 7 はどちらも、宣言した tsconfig を基準に解決します。(4d5e801ed)
- `buildSidebarForSection` は、`items` が空のオブジェクト形式のサイドバー定義にも `initialPath` と `initialPathMode` を適用するようになり、`buildSidebarNavigation` と同じ結果になりました。以前は、空の `items` ではカテゴリで絞り込んだツリーをそのまま返し、これらの設定を無視していました。(31fe01015)
- ブラウザーが遅延読み込みする Mermaid の URL を 11.15.0 から 11.17.2 に固定更新し、11.16.1 で導入されたアドバイザリー修正を含めます。ローカルの npm audit は別途配信される CDN 依存グラフを検査しません。(76d637663)
- デスクトップのサイドバーとモバイルのドロワーは、クライアント遷移、文書全体の読み込み、再読み込み、戻る／進むのあいだ、それぞれのスクロール位置を保持します。ツリーを広げたあとも同じです。復元は移動先のツリーがその位置を保持できるようになってから行われるため、サイドバーの差し替えや一時的に空になったツリーで先頭へ戻りません。保存された 0 は復元されます。スナップショットがないときに 0 は書き込まれません。閉じたドロワーの保存位置は、再び開くまで履歴に残ります。記事のスクロール、フォーカス、絞り込み、開閉状態は変えません。(418b2f29c, 2b38ccf0a)
- 外観メニューを、ライト・ダーク・システムの 3 行だけのコンパクトなリストにしました。見出しと下部の説明文は表示しません。システムの行には端末の現在のライト／ダークを小さく表示し、ライトやダークを手動で選んでいるあいだも正しい値を示します。説明文の全文は、システムの選択肢のアクセシブルな説明として残ります。ポップアップは最終的な幅で自然な高さを測ってから配置するため、枠線のせいで内側に不要なスクロールバーが出ることはなくなりました。画面の下端付近ではトリガーの上に開き、内容の大きさが変わると位置を合わせ直します。開く操作、矢印キー、フォーカスの戻りでページはスクロールしません。Tab／Shift+Tab は行を巡回せずにメニューから出ます。(37e3b8b42, 7aba63e28)

### その他の変更

- zfb 4.5.0 が必要になりました。`@takazudo/zfb`、`zfb-runtime`、`zfb-md-wasm` の peer 下限を `^4.3.3` から `^4.5.0` に引き上げます。zfb 4.4.0 は YAML frontmatter パーサーを更新し、フラグメントを含む戻る／進むの遷移を修正しました。zfb 4.5.0 では、以前表示した同じパスのクエリ項目への戻る／進むも復元し、フォームのリセット時に別のラジオグループの状態が消える問題も修正しました。CSS コンパイラーと `ErrorBoundary` の API も任意で利用できます。このリリースと合わせて zfb ファミリー（使用する場合は `zfb-adapter-cloudflare` も）を 4.5.0 に更新してください。(48a224468, 4f9d0c26f)
- Codex リソースの TOML パーサーを smol-toml `^1.9.1` に更新します。設定の日付やエージェントのメタデータを保持し、キー走査の範囲を制限する修正を取り込みます。(05e3fb5e7)
