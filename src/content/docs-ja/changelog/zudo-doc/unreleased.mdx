### バグ修正

- グローバル CSS に `img, svg, video, canvas, audio, iframe, embed, object { display: block }` のようなレイヤー外のメディアリセットを含むプロジェクトで、モバイルのサイドバートグルが 2 つのアイコンを同時に表示しなくなりました。これまで非アクティブなアイコンは Tailwind の `.hidden` ユーティリティで非表示にしていましたが、`.hidden` は `@layer utilities` 内に出力されるため、レイヤーに属さない作者スタイルはソース順に関係なくカスケードレイヤーの優先順位ですべてのレイヤー付きルールに勝ちます。その結果、両方のアイコンが `display: block` となって縦に並び、トグルが X とハンバーガーを同時に表示する 48px のコントロールになっていました。非アクティブなアイコンはインライン宣言で非表示にするようになり、コンシューマー側のスタイルシートから上書きされなくなりました。

### その他の変更

- `@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-md-wasm` の peer dependency 下限を `^2.20.1` に更新しました。2.20.1 はリリースメタデータのみの更新で、パッケージ固有の変更を報告しているパッケージはなく、公開された tarball の差分は各パッケージ自身のバージョンフィールドとプラットフォームバイナリの固定指定に限られます。zudo-doc の設定移行は不要です。
