### その他の変更

- 公開済みの zfb 4.5.4 系を必須とし、`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` の peer 下限を `^4.5.2` から `^4.5.4` に引き上げます。4.5.3 の MDX コンパイル修正として、HtmlPreview のテンプレートリテラルのプロパティなど、複数行の式が記述どおりの空白を保つ修正と、小数の比較を含むテンプレート文字列が `Unexpected numeric literal` でコンパイルに失敗しなくなる修正を取り込みます。また 4.5.4 のアイランド修正により、ページタイトルや Markdown 本文など、ブラウザーのグラフ外の編集で出力されるアイランドの JavaScript が変わらなくなります。zfb 系（使用時は `zfb-adapter-cloudflare` も）をまとめて更新してください。
