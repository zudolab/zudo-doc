### その他の変更

- 公開済みの zfb 4.7.0 系を必須とし、`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` の peer 下限を `^4.5.2` から `^4.7.0` に引き上げます。4.5.3 の MDX コンパイル修正として、HtmlPreview のテンプレートリテラルのプロパティなど、複数行の式が記述どおりの空白を保つ修正と、小数の比較を含むテンプレート文字列が `Unexpected numeric literal` でコンパイルに失敗しなくなる修正を取り込みます。また 4.5.4 のアイランド修正により、ページタイトルや Markdown 本文など、ブラウザーのグラフ外の編集で出力されるアイランドの JavaScript が変わらなくなります。さらに 4.6.0 では、CLI の HTTPS クライアントに RUSTSEC-2026-0381 と RUSTSEC-2026-0382 の修正が入り、ビルド用シャドウにはページから実際に到達できる pnpm ストアのパッケージだけが配置され、SSR シャドウとプラグインの仮想モジュールに関する Windows のパス不具合 2 件が修正されます。4.7.0 では、ページ/SSR とアイランドのバンドラーが esbuild から Rolldown に変わるため、更新後の最初のビルドで出力されるアイランドのアセットハッシュが変わります（`ZFB_BUNDLER=esbuild` で esbuild に戻せます）。また、パッケージ内で配布される TSX にもプロジェクトの tsconfig の JSX 設定が適用され（zfb#4407）、`@takazudo/zfb-md-wasm/highlight` などの `?url` リソースを読み込む Windows のアイランドビルドが失敗しなくなります（zfb#4413）。zfb 系（使用時は `zfb-adapter-cloudflare` も）をまとめて更新してください。
