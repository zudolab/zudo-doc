- ブラウザーの「戻る」「進む」で別のセクションに移動するとき、履歴の各ページでサイドバーのスクロール位置が復元されるようにしました。
- Markdownがエクスポートされている記事のヘッダーに、**Markdown をコピー**ボタンを追加しました。サイト全体またはページ単位で表示を切り替えられ、手動コピーにも対応しています。
- メニューを開いたときに、モバイルのサイドバーがヘッダー直下からビューポートの下端まで広がるようにしました。
- `docSources` でラベルが複数行にまたがるリンクを修正しました。マッピング済みのリンクは生成ページを参照し、未マッピングの参照は読めるテキストとして残してビルド時に警告します。
