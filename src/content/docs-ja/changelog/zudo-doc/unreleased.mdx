### バグ修正

- ダイナミックページトランジション中、遷移先のマークアップに置き換わる場合もヘッダーを静止させ、同じナビゲーションカテゴリ・言語・バージョン・ツリー内ではデスクトップサイドバーも静止させます。遷移先の最新の内容と既存のサイドバーの状態管理を維持し、変化する記事と目次は引き続きアニメーションします。サイドバーの表示・非表示の遷移は `hide_sidebar` を使うページにも対応します。読み込み中の表示はヘッダーやデスクトップサイドバーを暗くせずにコンテンツ領域を覆い、ページのアニメーションには混ざりません。コンテンツの差し替えまたはナビゲーションの中止時に解除します。(#4580)

### その他の変更

- 対応する Node.js の実行環境を現在の本番向け LTS 系列である Node 24（`>=24 <25`）に変更し、Node 22 のサポートを終了します。この下限変更は公開前にリリース方針の確認が必要です。
- GHSA-238p-pmpm-9mq7 の修正に合わせ、オプショナルな KaTeX ピアの下限を `^0.18.2 || ^0.19.0` に引き上げ、0.16.x のサポートを終了します。内部の色セレクターを更新し、サーバー側レンダリング、エラー表示、KaTeX なしの数式無効ビルドを保ちます。数式を使うホストは対応バージョンとローカル CSS のインポートが必要です。互換性の下限変更のため公開前にリリース方針の確認が必要で、npm の修正はまだ未リリースです。
- 公開済みの zfb 4.5.2 系を必須とし、開発時の `public/assets/` の即時配信、明示的な MDX テーブルと 1 行のコンパクトなテーブルの修正、ルート公開後にのみ表示される `zfb dev` の準備完了表示を取り込みます。zfb の peer 下限は `^4.5.2` です。関連パッケージをまとめて更新してください。
