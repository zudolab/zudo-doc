### 機能追加

- オプトインの `headerBrand` 設定（`false | { icon: string }`、デフォルト `false`）を追加しました。ヘッダーのサイト名の前に、文字色で塗られる（CSS マスク）装飾用の正方形アイコンを表示します。`/` で始まるパスにはサイトの `base` が 1 回だけ付与され、それ以外の URL はそのまま使われます。`icon` が空または未指定（あるいは `true`）の場合は設定解決時にエラーになります。サイト名はリンクのアクセシブルネームのままで、長い名前は引き続き省略記号で切り詰められ、アイコン設定中はテーマパックの先頭エンブレムが非表示になります。
- ホームのヒーロー `<h1>` に、サイト名のスタイル用フックとして `data-zd-site-name` 属性を追加しました。

### ショーケース

- ショーケースサイトが公式の zudo-doc アイデンティティを採用しました。ヘッダーのブランドアイコンにシンボル、ファビコン一式、ソーシャルカード、Jost 600 で組んだブランド名を使用します。

### その他の変更

- zfb 5.1.0 が必須になり、`@takazudo/zfb`・`zfb-runtime`・`zfb-md-wasm` の peer 下限を `^5.0.1` から `^5.1.0` に引き上げます。zfb 5.1.0 には islands のビルドガードが追加され、出力された islands チャンクが islands エントリーを import している場合にビルドが失敗するようになりました（本番ではその import が 404 になるため）。それ以外のチャンク分割は変わらず、`data-zfb-build` の識別子を除けば出力ページのバイトは 5.0.1 と同一です。このリリースと合わせて zfb 系（使用時は `zfb-adapter-cloudflare` も）を 5.1.0 にまとめて更新してください。
