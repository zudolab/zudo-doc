### バグ修正

- サイトマップの `<lastmod>` は、すべての URL にビルド日を入れる代わりに、各ドキュメントページのドキュメント履歴にある最終更新日を使うようになりました。ページの「更新日」表示と同じ日付です。日付が分からないルート（ホームとロケールのトップ、タグページ、アセットページ、バージョン付きページ、および `docHistory` が無効な場合や ドキュメント履歴の生成を省略した場合の全ページ）には `<lastmod>` を出力しません。`@takazudo/zudo-doc/route-enumerators` に `enumerateSitemapEntries` を追加しました。`enumerateAllRoutes` は変わりません。(#4784)
