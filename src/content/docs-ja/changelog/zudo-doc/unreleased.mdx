- ブラウザーの「戻る」「進む」で別のセクションに移動するとき、履歴の各ページでサイドバーのスクロール位置が復元されるようにしました。
- Markdownがエクスポートされている記事のヘッダーに、**Markdown をコピー**ボタンを追加しました。サイト全体またはページ単位で表示を切り替えられ、手動コピーにも対応しています。
- エージェント向け Markdown では、インデントされたタブ内のコードを保持し、標準のアドモニションと SiteTreeNav のグループ化・順序・ロケール規則を反映します。サイトマップには、Git 履歴があるアセットビューアーページの更新日を出力します。
- メニューを開いたときに、モバイルのサイドバーがヘッダー直下からビューポートの下端まで広がるようにしました。
- `docSources` でラベルが複数行にまたがるリンクを修正しました。マッピング済みのリンクは生成ページを参照し、未マッピングの参照は読めるテキストとして残してビルド時に警告します。
- デフォルトの SiteTreeNav のカテゴリーカードに、described バリアントと同じ余白を設定しました。狭いコンテナーでの小さめの余白も同様です。
- パッケージ提供ルートが、パッケージのコンパイル済みルートモジュールを直接読み込むようになりました。ビルド時にルートのソースをプロジェクトの `.zudo-doc/routes-src/` にコピーしなくなりました。既存の `.zudo-doc/` ディレクトリはそのまま残り、削除しても構いません。`./routes-src/*` のエクスポートは引き続き公開しています。
