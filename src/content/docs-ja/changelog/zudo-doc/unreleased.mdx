### 破壊的変更

- 11.0.0 で削除した `findInPage` キーが設定に残っている場合、`zudoDoc()` はそれを無視せず `TypeError` を投げるようになりました。メッセージがキーの削除を案内します。`findInPage` を含まない設定には影響しません。(#4763)

### 機能

- 複数のロケールに実際のコンテンツがあるページは、canonical リンクの後に `<link rel="alternate" hreflang>` で互いにリンクするようになりました。自身への参照と、デフォルトロケールのページを指す `x-default` も含みます。サイトマップにも同じ対応が `xhtml:link` の代替リンクとして載ります。対象はホームページと最新版のドキュメントページで、フォールバックのみのページ、バージョン付きページ、タグページは対応付けません。`siteUrl` がない場合や単一ロケールのサイトでは何も変わりません。`@takazudo/zudo-doc/route-enumerators` に `getDocLocaleAlternates` と `getHomeLocaleAlternates` を追加し、サイトマップのエントリに省略可能な `alternates` フィールドを追加しました。(#4787)

### バグ修正

- サイトマップの `<lastmod>` は、すべての URL にビルド日を入れる代わりに、各ドキュメントページのドキュメント履歴にある最終更新日を使うようになりました。ページの「更新日」表示と同じ日付です。日付が分からないルート（ホームとロケールのトップ、タグページ、アセットページ、バージョン付きページ、および `docHistory` が無効な場合やドキュメント履歴の生成を省略した場合の全ページ）には `<lastmod>` を出力しません。`@takazudo/zudo-doc/route-enumerators` に `enumerateSitemapEntries` を追加しました。`enumerateAllRoutes` は変わりません。(#4784)
