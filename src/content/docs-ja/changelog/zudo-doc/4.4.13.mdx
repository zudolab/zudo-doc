リリース日: 2026-07-30

### バグ修正

- テーマパック利用時のソフトナビゲーションでデフォルトの見た目が一瞬表示される問題を修正 — zfb の SPA head スワップ前に、遷移先ドキュメントへ対応するパックのスタイルシート link を注入するようにした。これによりロード済みの link が削除・再取得されずそのまま維持される (da3c9d9)

### その他の変更

- SPA ナビゲーションと履歴操作をまたいでテーマパックの link が削除されないことを e2e テストで固定 (a6dbcfd, 1cee0df, 8615097)
- zfb ファミリーを 0.1.0-next.99 に更新 (d48d2e1)
