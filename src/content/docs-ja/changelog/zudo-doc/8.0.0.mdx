リリース日: 2026-10-24

### 破壊的変更

- `@takazudo/zudo-doc/plugins/optional-peers` エクスポートを削除しました。この回避用プラグインを明示的に登録している場合は削除してください。拒否処理付きのオプショナル import は ZFB が直接扱います。
- ZFB 5.0.1 以降の 5.x 系が必要になりました。ZFB 本体、ランタイム、Markdown WASM を一緒に更新してください。ドキュメント履歴を使う場合は `@takazudo/zudo-doc-history-server` も 8.x に更新してください。Node.js の下限は引き続き 24 です。

### 機能

- `siteTreeNavInitiallyCollapsed` を追加しました。ホームページと MDX のサイトツリーで、指定した完全なカテゴリスラッグを任意の深さで初期状態から閉じられます。リンクと切り替えボタンは引き続き利用できます。(fb4a6e3cf)

### バグ修正

- ZFB 5.0.1 を採用し、遅延読み込みするアイランドが未公開の `islands.js` を要求する問題を修正しました。
- タブパネル内の本文の余白を修正しました。(5c2f52b92)
- 隣接する見出しの余白と、テーマパックの見出し階層を改善しました。(2969bd803)

### その他の変更

- Node.js の上限を撤廃し、24 以降を受け入れるようにしました。CI で検証しているのは引き続き Node 24 LTS です。(d5336a24b)
- MCP SDK を 1.32.2 に更新しました。
