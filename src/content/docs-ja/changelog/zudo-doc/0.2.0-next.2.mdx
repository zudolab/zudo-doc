内部的な整理とリリースパイプラインの堅牢化を目的としたメンテナンスプレリリースです。ユーザー向けの API 変更はありません。

### 変更点

- **非推奨だった `ai-chat-worker` パッケージを削除しました。** AI チャット API は SSR の `/api/ai-chat` エンドポイントで提供されます。スタンドアロンの Cloudflare Worker パッケージはリポジトリから削除されました。
- **リリースパイプラインの堅牢化。** 内部の `@takazudo/zudo-doc*` スキャフォールドのピンがドリフトしないようにガードし、公開対象パッケージのユニットテストとルートのユニットテストを PR CI で実行するようにし、ピンパリティチェックの失敗時にファイルパスのガイダンスを復元しました。
