リリース日: 2026-06-27

### 機能

- ホスト専用のMDXコンポーネントオーバーライドをパッケージ提供のドキュメントルートに接続し、パッケージドキュメントルートでもホストページと同様にコンテンツタイポグラフィが描画されるようにしました。 (37458437, #2390)
- `EJECTABLE`マップに6つのアイランドのswizzleポイントを追加し、ダウンストリームプロジェクトがeject・カスタマイズできるインタラクティブアイランドの範囲を拡張しました。 (2eba7863, #2388)
- `cjkFriendly`設定を`zudoDocPreset()`経由で接続し、CJK向けタイポグラフィを手動設定なしでプリセットから設定できるようにしました。 (bf0a94c7, #2387)

### バグ修正

- カード説明文のspanにもホバー時のアクセント表現を適用し、nav-indexingカード全体との見た目の一貫性を確保しました。 (341b52fa)
- 生成プロジェクトのスキャフォールドにおける`zod`の下限を`^4.3.6`に引き上げ、新規スキャフォールドが互換性のあるバリデータをインストールするようにしました。 (ff2317f5)

### その他の変更

- ファーストパーティの`@takazudo/*`ビルドツールチェーンを更新しました。`@takazudo/zfb`、`@takazudo/zfb-runtime`、`@takazudo/zfb-adapter-cloudflare`を`0.1.0-next.67`へ、`@takazudo/zudo-doc-history-server`を`^1.0.2`へ。 (30d9e187)
