リリース日: 2026-09-04

### 機能

- アセットページの詳細サイドレールを、トグルタブで折りたたみ・展開できるようにしました (`0eee44478`)。

### バグ修正

- コードアセットを独自のレイアウトではなく共有の詳細サイドレール経由で表示するようにしました (`bcfd3c0dc`)。
- レールの折りたたみ中も詳細カードの幅を固定し、アニメーション途中で内容が回り込まないようにしました (`a052aac2e`)。
- 詳細レールの折りたたみで描画だけでなくグリッド行自体を畳むようにし、余白が実際に解放されるようにしました (`856ad6dd6`)。
- prose の `dt`/`dd` ルールが Details のグリッド行を崩す問題を修正しました (`9422069e2`, `5beb96506`)。
- `settings.sitemap` が有効な場合のみ `/sitemap.xml` を注入するようにしました (`40c89e59a`)。
- 言語切り替えの開閉リストにアクセシブルな名前を付与しました (`597c74828`)。

### その他の変更

- zfbのピア依存関係および開発依存関係の一式を2.15.0へ更新しました (`d9f5b2f64`)。`ts`・`typescript` のコードフェンスがTypeScriptグラマーに、`tsx` がTypeScriptReactに解決されるようになりました。これまではいずれもJavaScriptのハイライトにフォールバックしていました。トークンのクラスはzfbの既存のセマンティックロール語彙のままなので、テーマ側に新しいルールは不要です。zfbのコンテンツパイプラインのフィンガープリントがv3に上がるため、アップグレード後の最初のビルドではキャッシュ済みコンテンツが再レンダリングされます。
