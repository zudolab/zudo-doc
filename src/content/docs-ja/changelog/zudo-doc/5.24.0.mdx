### 機能

- ホームページの h2 見出し（コンパクトイントロ、サイトマップ、Tags）が共通の `zd-home-heading` スタイルを使うようになり、テーマパックの h2 装飾を打ち消します。また Tags セクションの前に区切り線を追加しました。 (9ca2eef7)

### バグ修正

- Academia テーマパック: ホームのヒーロータイトルがパックの論文タイトル中央揃えを継承せずアイデンティティブロックの揃えに従い、ホームの区切り線が中央に配置されるようにしました。 (81266a2b)
