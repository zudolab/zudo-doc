リリース日: 2026-06-29

**メジャー**リリースです。`@takazudo/zudo-doc` のホスト配線まわりを統一された `ChromeContext` に集約しました。レンダリング結果（HTML/CSS）は 1.3.0 と**バイト単位で同一**で、破壊的変更はファクトリの API のみで出力には及びません。

### 破壊的変更

- `@takazudo/zudo-doc`: 公開されている chrome/render/data ファクトリ（`createHeadWithDefaults`、`createHeaderWithDefaults`、`createSidebarWithDefaults`、`createFooterWithDefaults`、`createRenderDocPage`、`createNavSourceDocs`、`createDoc*` 系など）が、これまでの広いパラメータバッグではなく単一の統一された `ChromeContext` を受け取るようになりました。これらのファクトリを呼び出していたホスト側のコードは、新しい `createRouteContext` + `createChrome` ビルダーで `ChromeContext` を組み立てて渡す必要があります。出力は変わりません（`API.md` を参照）。(df2a57f6, #2424)

### 機能

- `@takazudo/zudo-doc`: 新しい公開ビルダー `createRouteContext(payload)` と `createChrome(context, hostBindings)` を追加し、`@takazudo/zudo-doc/route-context` と `@takazudo/zudo-doc/chrome` からエクスポートしました。パッケージ側の chrome 再構築が、注入されるパッケージルートとホストアダプタの双方で共有される公開ビルダーになりました。(9f0ac9a0, b14c3226, #2423)
- `create-zudo-doc`: 生成されるプロジェクトが、約34個のコンポーネント別配線シェルの代わりに、単一の `pages/lib/_chrome.ts` ホストアダプタ（＋ vitest セーフな `_route-context.ts` シーム）を出力するようになりました。(791caf87, #2429)

### その他の変更

- ホストの約35個のファクトリ配線シェルを統一アダプタに集約しました（ホストコード −648 行）。バイトパリティ＋アイランド到達性ゲートで、レンダリングされる HTML/CSS が同一であることを保証しています。(#2427, #2428)
- `@takazudo/zudo-doc` の `API.md` を 2.0 契約に合わせて書き直し、public-API および eject スナップショットを更新しました。(5ed727c1, #2425)
- 不要・重複ファイルを削除し、tag-vocabulary の型を `@takazudo/zudo-doc/settings` への再エクスポートに統一しました。(b0f7bf80, 48634b5a, #2422)
