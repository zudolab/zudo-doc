リリース日: 2026-08-13

### 機能

- create-zudo-doc: 新しい**Claudeスキル（ライティング）**スキャフォールド機能（`--claude-skills-writing`、デフォルト無効）— 新しい`zudo-doc-writing` Claude Codeスキルを生成プロジェクトに同梱します。ドキュメント執筆 + ナビゲーション構造のガイド（ナビゲーションツリーを先に計画するワークフロー、3階層ナビゲーション、ファイル構造＝ナビゲーションの原則、カテゴリインデックスページ、`sidebar_position`の徹底、フロントマタースキーマ、h1禁止ルール、相対`.mdx`リンク、アドモニション構文）により、AI支援でのドキュメント執筆が混沌としたナビゲーションを生むことを防ぎます。既存の「Claudeスキル（ユーザー向け）」チェックボックスからは独立しています。(b37e28e5, #3383)

### バグ修正

- writing-rulesスキルとドキュメントの書き方ガイドの古い記述を修正：デフォルトのフロントマタースキーマは`.passthrough()`であり（カスタムキーは拒否されず保持される — フレームワークフィールドのタイプミスはエラーにならず黙って無視される）、アドモニションセットには`caution`タイプ（`Caution`コンポーネント、およびJSX専用の`Important`コンポーネント）が含まれます。(9acbc838, 3f338647, #3384)

### その他の変更

- Claudeスキルガイド（EN+JA）を2つの独立したオプトインスキル機能を軸に再構成し、同梱スキルがモノレポからのそのままのコピーであるという古い記述を修正しました。(4511619d)
- テンプレートドリフトチェック：テンプレート専用の`zudo-doc-writing`スキルを許可リストに追加しました（正しさはジェネレーターのvitestスイートで保証されます）。(821f6602)
