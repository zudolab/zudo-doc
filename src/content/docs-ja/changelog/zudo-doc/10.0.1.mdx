### バグ修正

- テーマ CLI が、`zfb.config.ts` 内の補間テンプレートリテラルの隣にある `themePack` を読めるようになりました。`${...}` は不透明な範囲のままなので、list と apply は後続の `themePack` を見つけられます。`themePack` を省略した場合は Graphite として検出済みと報告します。設定の構文エラーは、読めないファイル向けの汎用メッセージではなく、そのエラー内容を表示します。安全に置き換えられない値は、これまでどおり apply が拒否します。(7e5c783b)
