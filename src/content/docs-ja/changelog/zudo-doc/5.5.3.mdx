- zfb ツールチェインを 2.5.2 に更新しました。空行を挟んだディレクティブのネスト、分割された形の連結記法の認識、兄弟要素スキャンへのフェンス状態の引き継ぎ、JSX 再構築時にネストされた改行が失われる問題が修正されています。 (f69f5c7b6)

### その他の変更
