リリース日: 2026-07-18

### 機能

- テーマパックのフォントがグローバルな body フォントシームを介してアプリシェル（ヘッダー、サイドバー、TOC、パンくず、ページャー）にも適用されるようになりました。サーフェスごとのクロームフォントトークンで細かい制御も可能です (f84b2bd2)

### バグ修正

- サーフェスごとのクロームフォントノブが継承に頼らずシームトークンに固定されるよう修正 (dbd95365)
- ドキュメント: モバイルクロームがテーマパックのフォントトークンを除去するという誤った記述を修正 — モバイルフックもデスクトップ同様にトークンを受け取ります (3cbe0d45, 493f76dc)
- E2E: テーマパックフォントのスペックが body の font-family を直接検証し、バンドルされている foundry パックを対象にし、スイッチャーのハイドレーションを待つよう修正 (d88e4c5a, 218e8844)
- 手動編集された生成物の CHANGELOG.md をリバート — このファイルはコーパスから生成されます (ef43274c)

### その他の変更

- ツールチェーン: @takazudo/zfb ファミリー（zfb、zfb-runtime、zfb-adapter-cloudflare、zfb-md-wasm）を 0.1.0-next.89 に更新 (02268414)
- クロームフォントシームトークンとモバイルでの適用範囲に関する注意点のバイリンガルドキュメント (58cf6fc2)
- クロームフォントシームの恒久的な E2E リグレッションスペック (69af425e)
