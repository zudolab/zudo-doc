リリース日: 2026-09-06

### 機能

- パッケージ標準の Design Token Panel ビルダーが zdtp のネイティブなティアプレビューを宣言するようになりました。独自の `buildDesignTokenPanelConfig` を渡していないホストでも、ティアプレビューがそのまま利用できます（`3f34e3d08`）。

### バグ修正

- `design-token-panel-bootstrap` が定数と有効化条件をローカルで再定義せず、zdtp が分離して公開しているものをそのまま参照するようになりました。従来はブートストラップ側が独自のコピーを持っており、本来ミラーすべきパッケージとの乖離が生じていました（`cb2daf973`）。

### その他の変更

- 保存された Color のオーバーライドが、カラースキームとモードごとに分離されるようになりました。パッケージ標準のビルダーが `panelSettings.colorMode` に Default Light / Default Dark という別々のアイデンティティを宣言するため、一方のモードでの編集がもう一方のモードの既定値や保存内容を上書きすることはなくなり、モードを戻せばそのアイデンティティの保存内容が復元されます。Palette・Spacing・Font・Size のオーバーライドは、これまでどおりアクティブなテーマパック内でライト/ダーク共通です（`026497e69`）。
- オプショナル peer の `@takazudo/zdtp` の要求バージョンが `^0.5.0` になりました（従来は `^0.4.14`）。上流の 0.4.15 と 0.5.0 の 2 リリースぶんの追従です（`744b5c96c`、`a55182f9c`）。
- オプショナル peer の `@takazudo/zudo-doc-history-server` の下限が `^5.17.2` になりました（`744b5c96c`）。この下限は常に公開済みバージョンを指すため、設計上リリース中のバージョンより 1 つ遅れます。
