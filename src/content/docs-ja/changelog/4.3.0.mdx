リリース日: 2026-07-19

### 機能

- ドキュメントのコードフェンスと `HtmlPreview` のシンタックスハイライトを、セマンティックなデザイントークン駆動にしました。ブラウザプレビューは公開 zfb WASM ハイライターを遅延読み込みし、既存のカラースキームは互換性のあるセマンティックエイリアスを継承します。プロジェクト側の Shiki 依存関係とテーマ名設定は不要になりました (178f23321)
- `home.wide` でホームページをワイドコンテンツレイアウトに切り替えられるようにしました。パッケージ所有のルートおよびローカライズされたホームルートへ一貫して適用されます (d068ac346)
- 設定から特定ページを Doc History の対象外にできるようにし、レンダリング、履歴生成、パッケージ設定、生成プロジェクト設定まで同じマッチング動作を接続しました (e18c2e528)
- Hearth テーマの admonition アイコンをすべて揃えました (736c6c5e1)

### バグ修正

- Frontmatter のステータス pill は、薄い背景色を維持しながら、すべての配布テーマパック、ライト/ダークモード、セマンティックロールで WCAG コントラスト要件を満たすようになりました (2986d87c4)
- ショーケースがパッケージ所有のテーマ契約を正しく利用し、セマンティックな z-index utility をリテラルとして出力するよう修正しました (2ca79ca6b, 8fb517df6)
- テーマパックのフォント検証を厳格化し、生成される setup skill がメイン worktree のパスを確実に解決するよう修正しました (f9dd94d53, 4c2a508bb)

### その他の変更

- シンタックストークン移行、ワイドホームレイアウト、Doc History の除外、テーマ開発、ネットワーク公開時の注意事項について、英語・日本語ドキュメントを拡充しました
- ブラウザレベルのハイライト検証、pill の厳密なコントラスト検査、設定パリティテスト、互換性契約ガードを追加しました
