このページは`wide: true`フロントマターオプションのデモです。サイドバーが非表示になり、通常の読書幅にコンテンツを中央揃えする代わりに、`wide`によってコンテンツバンドがビューポートの大部分に広がります。

## 何が起きているか

コンテンツバンドがビューポートを埋めるように広がっています。使用しているフロントマターは以下の通りです：

```yaml
---
title: "デモ: ワイドレイアウト"
hide_sidebar: true
wide: true
---
```

## サイドバー非表示との比較

[サイドバー非表示](./hide-sidebar.mdx)のデモも同じくサイドバーを非表示にしますが、コンテンツは固定幅の読書カラムに中央揃えされたままです。ここでの唯一の違いは`wide: true`を加えている点で、これによりその上限がなくなり、コンテンツが利用可能な幅いっぱいに広がります。ブラウザの幅を広げて、2つのページを並べて比較してみてください。

## 使用場面

グリッド中心のページやダッシュボード的なページ（たとえば複数カラムのカードグリッドを持つランディングページや概要ページなど）、コンテンツを全幅に広げたほうが読みやすい場合に`wide: true`を使用します。`hide_sidebar`と自然に組み合わせられ、サイトのトップページでも使われているレイアウトです。

通常の本文には、上限のある標準の読書カラムのほうが読みやすいため、`wide`はコンテンツが幅の広さから本当に恩恵を受ける場合にのみ使用してください。

詳しくは[フロントマターリファレンス](../frontmatter.mdx#フィールド詳細-wide)をご覧ください。
