## 概要

**ドキュメントスキルシムリンカー**は、ドキュメントコンテンツから[Claude Codeスキル](https://docs.anthropic.com/en/docs/claude-code/skills)を作成します。セットアップ後、任意のClaude Codeセッション内でスキルを呼び出してドキュメントを参照できます。これにより、書き留めたすべてのドキュメントがAIのコンテキストとして利用可能になります。

これは特に次のような場合に便利です：

- このプロジェクトに依存する別のプロジェクトで作業しているとき
- 設定、コンポーネント、使用パターンに関する質問に答えるとき
- Claude Codeを通じてチームと組織のナレッジを共有するとき

## 仕組み

セットアップスクリプトは次のことを行います：

1. プロジェクト内に`.claude/skills/<skill-name>/`ディレクトリを作成
2. Claudeにドキュメントの使い方を伝える`SKILL.md`を生成
3. `src/content/docs/`ディレクトリをスキルフォルダにシムリンク
4. スキルを`~/.claude/skills/`にシムリンクし、グローバルに利用可能にする

セットアップ後、スキルは任意のClaude Codeセッションでスラッシュコマンドとして表示されます。

## セットアップ

セットアップスクリプトを実行します:

```bash
pnpm run setup:doc-skill
```

スキル名の入力を求められます。デフォルトは `<プロジェクト名>-wisdom`（例: `zudo-doc-wisdom`）です。

## 使い方

セットアップ後、任意のClaude Codeセッションでスキルを使用できます:

```
/zudo-doc-wisdom sidebar
```

Claudeが関連するドキュメント記事を検索し、回答に利用します。スキルはグローバルにシムリンクされているため、どのプロジェクトディレクトリからでも動作します。

### ワークフローの例

zudo-docでサイトを構築していて、フッターの設定方法を知りたいとします：

```
/zudo-doc-wisdom footer configuration
```

Claudeはドキュメントからフッターガイドを読み取り、ドキュメントに裏付けられた正確な回答を提供します。

## 作成されるファイル

セットアップスクリプトを実行すると、以下のファイルが作成されます:

```
.claude/skills/<skill-name>/
├── SKILL.md       # スキル定義（フロントマターと指示）
├── docs -> src/content/docs/         # 英語ドキュメントへのシムリンク
└── docs-ja -> src/content/docs-ja/   # 日本語ドキュメントへのシムリンク
```

グローバルシムリンク:

```
~/.claude/skills/<skill-name> -> .claude/skills/<skill-name>
```

<Note>

`.claude/skills/<skill-name>/`ディレクトリには、シムリンクと生成された`SKILL.md`が含まれます。お好みで`.gitignore`に追加しても安全ですし、スキル定義をチームと共有するためにコミットしても構いません。

</Note>

## 再実行

セットアップスクリプトはいつでも再実行できます。既存のシムリンクは自動的に置き換えられます。

```bash
pnpm run setup:doc-skill
```

<Tip>

プロジェクト名を変更したり、ドキュメントのディレクトリ構造を変更した場合は、セットアップスクリプトを再実行してスキルを更新してください。

</Tip>
