## 廃止されたもの

zudo-doc はネイティブのデスクトップアプリをサポートしなくなりました。2 つの Tauri モードはどちらもソースから削除されています。

- **Mode 1 — オフラインリーダー**（`src-tauri/`）：ビルド済みサイトをデスクトップアプリに同梱するもの
- **Mode 2 — 開発ラッパー**（`src-tauri-dev/`）：起動中の開発サーバーをネイティブウィンドウで表示するもの

`create-zudo-doc` はどちらのアプリもスキャフォールドしなくなり、Tauri 専用だったページ内検索機能（`findInPage` 設定と Cmd/Ctrl+F の検索バー）も削除されました。ブラウザでの Cmd/Ctrl+F は、ブラウザ自身の検索に戻ります。

:::note[公開済みの旧バージョン]
これはソースレベルでの削除です。削除前に公開済みのパッケージバージョンには Tauri 機能が残っており、これまでどおり動作します。削除がプロジェクトに反映されるのは、削除を含むリリースへアップグレードしたときだけです。破壊的変更のため、そのリリースはメジャーリリースになります。代わりとなるデスクトップアプリ、PWA、オフライン製品はありません。
:::

## 代わりに使うもの

- **ドキュメントの執筆とプレビュー：** `pnpm dev` を実行し、ブラウザでサイトを開きます。[開発](../getting-started/installation.mdx#開発)を参照してください。
- **ビルド済みサイトの確認：** `pnpm build` の後に `pnpm preview` を実行すると、`dist/` をローカルで配信できます。[ビルド](../getting-started/installation.mdx#ビルド)と[デプロイ](./deployment.mdx)を参照してください。

## 既存プロジェクトの後片付け

どちらかのモードを使っていたプロジェクトを Tauri サポートのないリリースへアップグレードするときは、古いネイティブ関連の要素を手動で削除してください。

1. **ジェネレーターの選択：** 保存済みの JSON プリセットやプログラマティック API の `features` 配列から `tauri` と `tauriDev` を外し、スクリプト化した `create-zudo-doc` コマンドから `--tauri` / `--tauri-dev` を外します。これらを有効にするとエラーになります。無効化する形式（`--no-tauri`、`--no-tauri-dev`、`--tauri=false`、`--tauri-dev=false`）は引き続き受け付けられ、何もしません。[create-zudo-doc](../reference/create-zudo-doc.mdx#機能)を参照してください。
2. **設定：** `zfb.config.ts` の `zudoDoc({ ... })` 呼び出し（または設定オブジェクト）から `findInPage` フィールドを削除します。
3. **インポート：** `@takazudo/zudo-doc/find-in-page` を直接インポートしている箇所を削除します。このエクスポートはもう存在しません。
4. **アプリのファイルとスクリプト：** `src-tauri/` と `src-tauri-dev/` ディレクトリを削除し、`package.json` から `dev:tauri`、`dev:tauri-dev`、`build:tauri`、`build:tauri-dev` スクリプトと、それらのためだけにあった補助スクリプトを削除します。

インストール済みのデスクトップアプリやユーザーごとのアプリデータが自動で削除されることはありません。自分でビルドしたアプリが不要になった場合は、ほかのアプリと同じようにお使いの OS の通常の方法でアンインストールしてください。
