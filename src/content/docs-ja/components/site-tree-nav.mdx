## 概要

`SiteTreeNav`は、展開可能なカテゴリカードのレスポンシブグリッドでドキュメントツリー全体を表示するクライアントアイランドコンポーネントです。カテゴリの展開・折りたたみが可能な、サイトマップ形式のドキュメントページ一覧を提供します。

<Info>

`SiteTreeNav`はMDXコンテンツで直接利用**できます**。グローバルMDXタグとして登録されているため、インポートなしで`<SiteTreeNav />`と書くだけで動作します。以下のライブデモで使用している`SiteTreeNavDemo`タグは、まったく同じ自己データ取得型のラッパーに解決されます。MDX内ではこの2つのタグ名は同じものとして使えます。

これは、`@takazudo/zudo-doc/site-tree-nav-island`から提供される、`tree`プロップを直接受け取る生の`SiteTreeNav`とは別のコンポーネントです。そちらは自身でデータを取得せず、すでに`tree`を持っているページモジュール向けです。両方の使い方は下記の[使い方](#使い方)を参照してください。

</Info>

## 使い方

### MDXコンテンツでの利用

`.mdx`ファイル内でグローバルMDXタグを直接使用します。インポートは不要です：

```mdx
<SiteTreeNav />
```

プロップは不要です。現在のロケールのドキュメントコレクションを自身で取得し、ナビゲーションツリーを構築して、インタラクティブなアイランドをレンダリングします — 上記の`SiteTreeNavDemo`と同じラッパーが使用されます。

ツリーから非表示にするカテゴリは、`zfb.config.ts` の [`siteTreeNavIgnore`](../guides/configuration.mdx#ホームページ-sitetreenavignore) で設定します。[`siteTreeNavSecondary`](../guides/configuration.mdx#ホームページ-sitetreenavsecondary) はホームページ専用の設定で、このコンポーネントには適用されません。そこに指定したカテゴリも、このコンポーネントのツリーにはそのまま表示されます。

[`siteTreeNavInitiallyCollapsed`](../guides/configuration.mdx#ホームページ-sitetreenavinitiallycollapsed) に指定したカテゴリは、両方の MDX タグとパッケージ所有のホームページで最初から閉じます。カテゴリのリンクと切り替えボタンは表示され、訪問者は子要素を展開できます。

### ページモジュールでの利用

すでに`tree`を持っているページモジュール（例：`buildNavTree` + `groupSatelliteNodes`で構築済み）では、代わりに`tree`プロップを直接受け取る生のコンポーネントをインポートできます：

```tsx
import { SiteTreeNav } from "@takazudo/zudo-doc/site-tree-nav-island";

export default function IndexPage() {
  return (
    <SiteTreeNav
      tree={tree}
      categoryOrder={categoryOrder}
      categoryIgnore={["inbox", "develop"]}
      initiallyCollapsedCategorySlugs={["zudo-wind/utilities"]}
    />
  );
}
```

生のアイランドの `categoryIgnore` プロップは、サイト全体の [`siteTreeNavIgnore`](../guides/configuration.mdx#ホームページ-sitetreenavignore) 設定に相当する呼び出し単位の指定です。パッケージのホームページと MDX タグは、ここにその設定を渡します。

このリポジトリ自体のホームページ（`pages/index.tsx`）は、このアイランドを直接呼び出していません。解決済みのロケールを`prepareHomeData()`に渡し、その結果を`HomePageView`（どちらも`@takazudo/zudo-doc/home-page`から提供）に渡しています。`HomePageView`はヒーローセクションやタグセクションと一緒に、内部で`SiteTreeNav`をレンダリングします。

このコンポーネントは展開・折りたたみのインタラクティブ機能にシグナルを使用するため、zfbのアイランドランタイムを介してクライアントでハイドレートされます。

## プロップ

以下のプロップは、生の`SiteTreeNav`アイランド（`@takazudo/zudo-doc/site-tree-nav-island`）に対するものです。MDXタグはデータプロップを一切受け取らず、現在のロケールに対して`tree`/`categoryOrder`を自身で解決し、任意の`ariaLabel`・`variant`・`idPrefix`だけを転送します。

| プロップ | 型 | デフォルト | 説明 |
|------|------|---------|-------------|
| `tree` | `NavNode[]` | （必須） | コンテンツコレクションから構築されたナビゲーションツリー |
| `categoryOrder` | `string[]` | — | トップレベルカテゴリのカスタム並び順 |
| `categoryIgnore` | `string[]` | — | ツリーから非表示にするカテゴリスラッグ（パッケージのホームページと MDX タグはここに `siteTreeNavIgnore` を渡します） |
| `initiallyCollapsedCategorySlugs` | `string[]` | `[]` | 任意の深さで初期状態を閉じるカテゴリの完全一致スラッグ |
| `ariaLabel` | `string` | `"Site index"` | nav要素のアクセシビリティラベル |
| `variant` | `"default" \| "described"` | `"default"` | `"described"` で説明とカテゴリごとの文書数を追加（[説明付きのバリエーション](#説明付きのバリエーション)を参照） |
| `countLabels` | `{ one: string; other: string }` | 英語 | 説明付き表示の文書数テンプレート（`{count}` を置換）。MDX タグとホームページは翻訳済みのラベルを渡します |
| `idPrefix` | `string` | `"zd-site-tree"` | 開閉対象の id の接頭辞。1 ページに複数のツリーを置くときはそれぞれ別の値にします |

## 説明付きのバリエーション

`variant="described"` は同じツリーと操作のまま、文書がすでに持っている説明と、カテゴリごとの文書数を加えます。説明のないカテゴリや文書には空きスペースを作りません。カードの列幅は約 22rem です。

```mdx
<SiteTreeNav variant="described" idPrefix="described" />
```

カテゴリが 1 つだけで、その枠の幅が 48.75rem 以上あるときは、カテゴリの概要が文書ツリーの横の列（最大 20rem）に移ります。狭い枠では概要をツリーの上に積みます。切り替えはウィンドウではなくコンポーネント自身の幅で決まるので、広い画面でも狭い列の中では縦に積まれます。[ホームページの `sections` 設定](../guides/configuration.mdx#ホームページ-home-ナビゲーションセクションの構成)はこのバリエーションを使います。

## カテゴリのカバー画像

トップレベルのセクションは、ホームページのサイトインデックスにある自分のカードに画像を表示できます。そのセクションの `index.mdx` に [`cover`](../guides/frontmatter.mdx#フィールド詳細-cover) フロントマターを追加します。

```mdx title="src/content/docs/guides/index.mdx"
---
title: Guides
sidebar_position: 2
cover: /img/covers/guides.png
---
```

- **表示される場所。** パッケージのホームページ（`/` と各ロケールのホーム）のサイトインデックスだけです。従来のサイトマップブロックと、[`home.sections`](../guides/configuration.mdx#ホームページ-home-ナビゲーションセクションの構成) の `site-tree` セクションのどちらでも表示されます。このページの例のような、文書内の `<SiteTreeNav />` タグや `<SiteTreeNavDemo />` タグではカバー画像は表示されません。
- **対象のカード。** トップレベルのセクションだけです。入れ子のカテゴリの `index.mdx` など、ツリーのより深い場所にある `cover` は無視されます。`siteTreeNavIgnore` で非表示にしたセクションや、`siteTreeNavSecondary` で補助の行に移したセクションにはカードがないため、カバー画像も表示されません。カバー画像のないカードの見た目は変わりません。
- **画像。** カードの最上部に、カードの枠線いっぱいに表示されます。1200:630 のボックスは画像の読み込み前に確保されます。画像はボックスを埋めるように切り抜かれる（`object-fit: cover`）ため、1200 × 630 の画像なら全体が見えます。遅延読み込みされ、装飾として扱われます（`alt=""`）。セクションのタイトルがすぐ下に表示されるためです。
- **パス。** ルートからの絶対パスで、通常は `public/` 内のファイルです。サイトの `base` は自動で前に付きます。外部 URL、`//` パス、バックスラッシュ、制御文字は、ビルド時のフロントマター検証で失敗します。
- **デフォルトと説明付きのバリエーション。** カバー画像はどちらでも同じで、カードの先頭、セクションのタイトルの上に表示されます。説明付きのバリエーションでは、説明と文書数がいつもどおりタイトルの下に続きます。セクションが 1 つだけで概要の列とツリーの列に分かれるときも、カバー画像は両方の列の上に、カードの全幅で表示されます。

生のアイランド `@takazudo/zudo-doc/site-tree-nav-island` は、`tree` のトップレベルのノードにある `coverHref` フィールドから画像を取ります。これはパッケージのホームページが `cover` と `base` から組み立てる、そのまま使える URL です。カバー画像を使ったホームページの完全な設定は、[カタログ](./home-hero.mdx#ホームページの構成例-カタログ)の構成例を参照してください。

## 特徴

- **レスポンシブグリッドレイアウト** — `repeat(auto-fill, minmax(min(18rem, 100%), 1fr))`により、モバイルの1カラムからワイドスクリーンの複数カラムまで適応
- **展開可能なカテゴリ** — 各カテゴリカードは折りたたみ可能で、デフォルトでは開いた状態
- **初期状態の折りたたみ** — 指定カテゴリはサーバー HTML ですでに閉じ、ハイドレーション後も操作可能です。他のカテゴリは開いたままです
- **階層的なツリー構造** — ネストされたページはインデントと破線のコネクタで表示します。どの縦線も 1.75rem のマーカー／開閉ボタン枠の中心に置くため、カテゴリのシェブロンアイコンとそのツリーの縦線がそろい、入れ子の縦線は親の枠付きボタンの下端中央から始まり、枝は複数行の行でも 1 行目に合い、最後の縦線は最後の枝で止まります。縦に積んだカテゴリでは最初の枝の上に短い導入線を残し、カテゴリ 1 つの左右分割では最初の枝から縦線を始めます
- **リンクと開閉の分離** — ページのあるカテゴリはリンクと、別の枠付き開閉ボタンを持ちます。ページのないカテゴリはラベルで開閉します。各ボタンは `aria-controls` で対象を示し、閉じた子要素はキーボード操作と支援技術の対象から外れます
- **カテゴリリンク** — トップレベルカテゴリは矢印アイコンとインデックスページへのリンクを表示
- **リーフページ** — 個別のドキュメントページはクリック可能なリンクとして表示

## ソース

`SiteTreeNav`は`@takazudo/zudo-doc`パッケージから提供されています。ページモジュールで使う場合は、生のアイランドを`@takazudo/zudo-doc/site-tree-nav-island`からインポートしてください。（このリポジトリ内では、アイランドのソースは`packages/zudo-doc/src/site-tree-nav-island/`にあります。）`<SiteTreeNav />` / `<SiteTreeNavDemo />`のMDXタグは、パッケージ所有のルート（`packageOwnedRoutes`、デフォルトで有効）によって自動的に組み込まれており、プロジェクト側で管理するファイルはありません。
