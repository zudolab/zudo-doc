設定で `math` が有効になっている場合（デフォルト：`true`）、`<MathBlock>` JSX コンポーネントを使用して KaTeX で数式をレンダリングできます。

<Info>

`$...$`、`$$...$$`、および `` ```math `` フェンスは **zfb では非対応です**。zfb の Rust MDX エミッタはこれらの構文を処理しません — 代わりに `<MathBlock latex="..." />` を使用してください（パッケージが公開する [`@takazudo/zudo-doc/math-block`](https://github.com/zudolab/zudo-doc/blob/main/packages/zudo-doc/src/math-block) を参照）。

</Info>

## インライン数式

`<MathBlock latex="..." />`（`block` プロップなし）を使用して、テキスト内に数式を埋め込みます。

数式 <MathBlock latex="E = mc^2" /> はインラインで表示されます。

```mdx
数式 <MathBlock latex="E = mc^2" /> はインラインで表示されます。
```

## ブロック数式

`block` プロップを追加すると、中央揃えのディスプレイ数式をレンダリングできます。

<MathBlock latex="\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}" block />

```mdx
<MathBlock latex="\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}" block />
```

## 設定

数式サポートは `zfb.config.ts` の `math` フィールドで制御されます：

```ts title="zfb.config.ts"
export default defineConfig(
  zudoDoc({
    // ...
    math: true, // デフォルトで有効
  }),
);
```
