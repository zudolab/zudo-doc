zfb の Markdown パイプラインは、常に有効な **Core（組み込み）** 機能と、`zfb.config.ts` の `markdown.features` で個別に有効化する **Opt-in（オプトイン）** 機能を提供します。

## Core 機能

以下の 8 機能は常に有効です。設定は不要です。

| 機能 | 説明 |
| --- | --- |
| [CJK Friendly](./cjk-friendly.mdx) | 中国語・日本語・韓国語（CJK）の文章に対して、スペーシングと改行処理を改善します。 |
| [Heading Links](./heading-links.mdx) | h2 以上の見出しにアンカーリンクを追加し、ページ内の直接リンクを可能にします。 |
| [Code Title](./code-title.mdx) | コードブロックに `title="…"` を設定すると、ファイル名や見出しバーを表示します。 |
| [External Links](./external-links.mdx) | 外部リンクに視覚的なインジケーターを自動付与します。 |
| [Resolve Links](./resolve-links.mdx) | 相対パスの `.mdx`/`.md` リンクをクリーンなドキュメント URL に解決します。 |
| [Strip .md Extension](./strip-md-ext.mdx) | 出力される内部リンクの href から `.md`/`.mdx` 拡張子を除去します。 |
| [Syntax Highlighting](./syntax-highlighting.mdx) | syntect によるビルド時コードハイライト（固定テーマ: `base16-ocean-dark`）。 |
| [Directives Registry](./directives-registry.mdx) | `:::note`、`:::tip`、`:::warning`、`:::danger`、`:::info`、`:::details` などのアドモニションディレクティブを提供します。 |

## Opt-in 機能

以下の 14 機能はデフォルトで無効です。`zfb.config.ts` の対応する `markdown.features.*` キーで個別に有効化してください。

| 機能 | 設定キー | 説明 |
| --- | --- | --- |
| [Admonitions Preset](./admonitions-preset.mdx) | `admonitionsPreset` | 標準のアドモニションディレクティブ（note/tip/warning/danger/info/details）を有効にします。 |
| [Mermaid](./mermaid.mdx) | `mermaid` | ` ```mermaid ` フェンスをクライアントサイドの Mermaid ライブラリで図として描画します。 |
| [Image Enlarge](./image-enlarge.mdx) | `imageEnlarge` | クリックで拡大できる `<figure>` に画像をラップします。 |
| [Heading Marker TOC](./heading-marker-toc.mdx) | `headingMarkerToc` | 各見出しにアンカーマーカーを付与し、TOC アイランドにデータを提供します。 |
| [GitHub Alerts](./github-alerts.mdx) | `githubAlerts` | `> [!NOTE]`/`[!TIP]`/`[!WARNING]`/`[!IMPORTANT]`/`[!CAUTION]` ブロック引用をアドモニションマークアップに変換します。 |
| [Reading Time](./reading-time.mdx) | `readingTime` | 推定読了時間を計算し、ページレベルのメタデータとして公開します。 |
| [GitHub Autolinks](./github-autolinks.mdx) | `githubAutolinks` | Issue 番号、クロスリポジトリ参照、コミット SHA を GitHub へ自動リンクします。 |
| [Code Enrichment](./code-enrichment.mdx) | `codeEnrichment` | コードブロックにタイトルバー、コピーボタン、diff/行ハイライト装飾を追加します。 |
| [Code Tabs](./code-tabs.mdx) | `codeTabs` | `:::code-group` ディレクティブを `<CodeGroup>` 経由でタブ付きコードパネルとして描画します。 |
| [Ruby](./ruby.mdx) | `ruby` | ルビ注釈サポートを追加します（`{base}^{ruby}` 構文）。next.13 では既知のブロック — #1815 参照。 |
| [TOC Export](./toc-export.mdx) | `tocExport` | ページの目次を `export const toc` 名前付きエクスポートとして出力します。next.13 では既知のブロック — #1814 参照。 |
| [Image Dimensions](./image-dimensions.mdx) | `imageDimensions` | ディスクのメタデータから画像に `width`/`height` 属性を付与します（next.13 では no-op）。 |
| [Link Validation](./link-validation.mdx) | `linkValidation` | ビルド時に内部リンクを検証し、壊れた参照に警告（またはエラー）を出します。 |
| [Transclude](./transclude.mdx) | `transclude` | `:::include{file="…"}` または `![[path]]` で別ファイルの内容を埋め込みます。next.13 では zudo-doc で無効化。 |
