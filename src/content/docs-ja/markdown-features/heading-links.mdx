**Core 機能** — 常に有効です。設定は不要です。

## 概要

`h2` 以上のすべての見出しに以下が自動的に付与されます。

1. GitHub-slugger 互換のルールで見出しテキストから生成されたスラグベースの `id` 属性。
2. 見出しテキストをラップする自己参照アンカー要素。読者がページ内の直接リンクをコピーできます。
3. 重複解消: 同じ見出しテキストがドキュメント内に複数ある場合、カウンターサフィックスが付与されます（`overview`、`overview-1`、`overview-2` など）。

## 例

以下の markdown 見出しは:

```md
## Introduction

## Introduction
```

次のように変換されます。

```html
<h2 id="introduction"><a href="#introduction">Introduction</a></h2>
<h2 id="introduction-1"><a href="#introduction-1">Introduction</a></h2>
```

## 他のページからのディープリンク

各見出しに安定した `id` が付与されるため、別のページの特定セクションにリンクできます。

```md
[Introduction を参照](./other-page.mdx#introduction)
```

## 補足

- スラグアルゴリズムは固定の GitHub-slugger ルールに従い、`zfb.config.ts` から変更できません。
- オプトインの Heading Marker TOC 機能は、このプラグインが生成した安定した見出し識別子に依存します。`headingMarkerToc` が有効な場合、Heading Links の後で実行されます。
