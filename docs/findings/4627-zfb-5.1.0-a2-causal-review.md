## Cause

The bump moves the ZFB family (`zfb`, `zfb-runtime`, `zfb-md-wasm` and `zfb-adapter-cloudflare`) from 5.0.1 to 5.1.0. Those package versions are inputs to the native build identity.

The only behavioural change upstream in 5.1.0 is the islands entry-import build guard (Takazudo/zudo-front-builder#4454). Chunking is unchanged, emitted page bytes differ only in the `data-zfb-build` identity, and the guard did not fire on this build.

Identity freshness is observed, not independently proven. The native identity stays in the fingerprint, and normalization and every assertion are unchanged.
