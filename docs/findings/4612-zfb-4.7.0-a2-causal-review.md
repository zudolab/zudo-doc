# A2 causal review — ZFB 4.7.0

The accepted three-page reference is the one #4607 established. This review comes before the reference update in PR #4612. It covers both changes on that branch: the zfb 4.7.0 family bump, where Rolldown becomes the default page/SSR and island bundler, and the `optional-peers` plugin that works around [Takazudo/zudo-front-builder#4429](https://github.com/Takazudo/zudo-front-builder/issues/4429).

Both captures were taken locally with the CI command (`ZUDO_A2_CAPTURE_DIR=… pnpm exec vitest run --config vitest.slow.config.ts --testNamePattern "A2 no-stub: injected routes render correct HTML"` in `packages/zudo-doc`), under Node 24.22.1:

- **Baseline:** a clean worktree of main `8c025393ce6a7e93b67724d3fe46108b7c175528` (zfb 4.6.0). All 20 assertions passed and reproduced the #4607 hashes.
- **Candidate:** clean head `39f1e8a81538b4c68d22b325c56937b437157a71`. The three strict fingerprints failed, and the other 17 selected assertions passed.

`python3 scripts/a2-causal-diff.py` compared the two captures with reference source `8c025393ce6a7e93b67724d3fe46108b7c175528`. It reported `DIFFERENCES_REQUIRE_REVIEW` / `OBSERVED_ONLY_UNVERIFIED_FRESHNESS`, with `residualEqual: true` and an empty residual diff on all three pages, and no changed stylesheets.

- **Lengths.** In 404, getting-started and coverage order, raw lengths are 57,025, 67,457 and 78,909. They are the same before and after the bump.
- **Build identity.** The pages contain 1, 2 and 4 `data-zfb-build` values respectively, and every one changes from `d5db75b78169675d` to `5f5ce2f672188e84`. The hashed islands bundle name moves with it.
- **Residual.** Replacing only those candidate values with the baseline value reproduces all three accepted normalized captures exactly, with no other byte differences.
- **New strict hashes,** in page order: `03f35ca1804358b7de19f873657afde9ac8900004b39c9240a1fe76e197c73dc`, `9046ec339da9d8583dfb638dc19492ec4377818cb6c18c7ef77e90d072dbe9a0` and `286ba4a83ab0f2faaaafcfc30635017beea63185b62a1799f661497f8807c128`.

The identity is native ZFB build metadata derived from the resolved browser graph. Two things move it here:

- Rolldown replaces esbuild as the islands bundler; its output is ~4% larger raw and ~4% smaller gzipped per the zfb 4.7.0 release notes.
- The `optional-peers` virtual modules replace the unresolved `katex` / `diff` specifiers in that graph while `math` / `docHistory` are off, which is the case for this fixture.

The rendered HTML is otherwise byte-identical.

`compiled.css` did not change. This update keeps the native identity in the fingerprint, the normalizer and every A2 assertion. Fresh final-head CI must still run and pass the strict A2 subset; this forensic comparison alone is not acceptance.
