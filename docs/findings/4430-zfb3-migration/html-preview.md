## Trusted payload review

| Site | Payload, parser context, and lifetime |
| --- | --- |
| `HighlightedCode` ordinary HTML `div` `rawHtml` | The public zfb WASM highlighter produces escaped semantic `pre.hi-root` markup. `getUsableHighlightHtml` rejects null/error results; fallback renders `code` as escaped text. `rawHtml` has no children, sits in a valid div, and is replaced by reactive updates. `Show` disposes the branch when the source panel closes. No nested islands, protocol comments, or scripts are generated by the highlighter. Browser highlight parity is still required. |
| `PreviewBase` imperative iframe `srcdoc` property | `buildSrcdoc` assembles author-trusted MDX/config `html`, `head`, `css`, `js` and external resource URLs. It is **not sanitized**; the unchanged sandbox default permits same-origin script execution and requires trusted authors or an explicit stricter sandbox. Generated lang/title are escaped. The string is assigned to a created iframe property, never inserted as outer rawHtml or rendered as iframe JSX. `onActivate` owns load listener/controller/iframe cleanup. Opaque iframe content has no nested zudo-react island wrappers or protocol comments from this component. |
| `buildSrcdoc` literal style/script/link markup | These are **inside** the iframe document string, not zudo-react `rawHtml` sites. Authored CSS/JS/head/HTML and URL strings retain their existing trusted-config contract; preflight and full-height style are package literals. Script/style closing-tag guards in the zudo-react rawHtml policy do not apply to this iframe document string. |

## Differences and verification

Eager SSR now emits the iframe reservation host without the iframe; activation appends exactly one iframe. The extra host div and client insertion are engine-mandated by #3361. Visible mode uses zfb's native `data-when` scheduling and keeps the existing height reservation. Preview controls, labels, sandbox/allow/title policy, code content and auto-height algorithm are otherwise intended to match v2. Remove the imperative shim only after a published native iframe fix passes browser proof.
