# Static and browser parity triage

This compares the **reconstructed** CI-faithful v2 baseline at `337b9f110793dccb4759bddd5273eab38cd9d2f0` (`/workspace/zudo-v2-baseline/dist`) with the captured current build from `84333fa7` (`/workspace/zudo-doc/dist`). It is not the canonical frozen reference. The main checkout has since been rebuilt; the findings below use the saved reports under `/tmp/zudo42-parity/`.

The static report has 787 shared routes, 2,366 hard differences, and no advisory differences. Its layer counts are: route manifest 1, islands 787, DOM 787, classes 787, and one each for CSS selectors, custom properties, media queries, and layers. The route manifest has 791 current routes versus 787 baseline routes: four additions (`/docs/guides/agent-export`, `/docs/guides/mcp-server`, and their `/ja/` routes), with no removals.

Island identity is stable: no island names or `skipSsr` values changed. Ten `DocHistory` marker paths shift on five pages in both English and Japanese (`configuration`, `llms-txt`, `search`, `create-zudo-doc`, `host-chrome-bindings`); the marker moved after additional earlier document content. Many bootstrap markers change serialized props from `null` to `{}` (`ClientRouterBootstrap`, `ImageEnlarge`, `MermaidEnlarge`, `DesignTokenPanelBootstrap`, `DesktopSidebarToggle`, `DesktopTocToggle`, `ConfiguredDesignTokenPanelBootstrap`, `PresetGenerator`), which is a transport-shape difference with the same island target. Real content prop changes are confined to navigation/TOC data: `SidebarToggle.nodes` and `SidebarTree.nodes` on 82 routes, `SiteTreeNav.tree` on four, and `Toc.headings`/`MobileToc.headings` on ten pages, reflecting added guides/integrations and headings.

DOM diffs on all routes are dominated by head-node shifts: current pages add `/llms.txt` (`rel=alternate`, `text/plain`) and per-document Markdown alternate links, shifting stylesheet and module-script positions. These are content/export additions, not CSS engine changes. Sampled external links on `/` and `/docs/getting-started/` retain their `_blank` target and `noopener noreferrer`; active sidebar state is retained, while inactive links now emit `aria-current="false"`. `bottom:0px` to `bottom:0`, and removed SVG `xmlns`/`focusable` attributes, are mechanical/normalized changes.

Most class churn is consistent with the Wind/CSS migration: spaces in arbitrary `calc()` class values serialize as underscores, unscoped arbitrary-selector utilities become authored `zd-*` helper classes, and `wrap-anywhere` is namespaced as `zd-wrap-anywhere`. `animate-pulse` disappears from skeleton previews where the v2 CSS had no matching rule/keyframes (computed animation was `none`); `version-switcher` is removed while its `data-version-switcher` behavior hook remains. One change is user-visible and needs explicit acceptance: heading permalink anchors move from always-visible accent/underlined links to `.hash-link` anchors hidden at rest and revealed on hover/focus. The current authored CSS implements that affordance; it is not just class serialization.

The CSS inventory differs by 226 added/343 removed selectors, 114 added/48 removed custom properties, 3 added/4 removed media queries, and 4 added/4 removed layer declarations. This is expected inventory churn from the v2-to-zudo-wind migration (including `--tw-*` to `--zw-*` and renamed layers), but the lexical inventory alone cannot establish computed-style equivalence.

The browser capture covers 64 states on each side across 12 routes and records 35 computed-style differences (2 `nav`, 2 `sidebarTree`, 17 `code`, 9 heading `link`, 4 `table`, 1 `admonition`). The guide sidebar/tree is 76px taller, consistent with the two added guide pages. The versions table is 24px taller and still needs its content change tied to an accepted update. Code block heights change while recorded font, line-height, width, and padding stay the same: html-preview 231→224px, Mermaid 312→302px, math 69→68px, design-token-panel 204→198px, and image-enlarge 177→172px; the admonition there is also 5px shorter. Parent review indicates the code markup spans match, so these remain unexplained computed differences pending investigation. The nine link diffs are the heading permalink change above: baseline accent-colored visible anchor versus current opacity-zero hash affordance. Both captures time out waiting for the Mermaid enlarge button (same 30s timeout), so that state is not comparable.
