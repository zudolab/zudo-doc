## Residual discovery contract

The original #3895 plain-object factory case **passes**. Its implementation was completed in upstream #3919, which intentionally bounds static factory discovery. The actual application still fails:

```text
owned island scanner preflight failed
unsupported island registration at packages/zudo-doc/dist/doc-body-end-islands/design-token-panel-island.js:21:7:
target DesignTokenPanelBootstrap has unsupported initializer:
call site at packages/zudo-doc/dist/chrome/derive.js:213:34 passes a non-literal argument
```

`chrome/derive.tsx` selects a host-provided component or the default and forwards it through dependency objects/spreads. Existing `FactoryContext.hostBindings.DesignTokenPanelBootstrap` accepts a component; the package owns the feature gate and Island mounting. Replacing it unconditionally with the default discards the host contract. Moving Island ownership to the host is a public seam migration, outside the binding conventions' exhaustive API-change list.

[Upstream #3992](https://github.com/Takazudo/zudo-front-builder/issues/3992) asks for a supported preserving adapter or explicit contract resolution. This is a residual enhancement/migration question, **not a claim that #3919's bounded fix regressed**. The documented composition route works as a build control; it is not yet an equivalent migrated application.
