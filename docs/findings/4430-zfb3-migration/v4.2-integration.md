Implemented consumer changes:

- `DesignTokenPanelBootstrap` keeps its public slot name but now accepts a **server boundary** with a fixed client target. Disabled or absent boundaries produce no marker/shim. Independent hostpanel mounting remains separate.
- The optional body-end `ThemePackSwitcher` dependency likewise receives a fixed-target server boundary; null registry, missing dependency, settings and pending-state behavior remain intact.
- `DocHistory` becomes a server-boundary slot. `DocHistoryBoundary` is exported through the existing `doc-history-area` subpath. It owns idle/skip-SSR mounting, consumes the SSR fallback server-side and transports only serializable client data. Root, generated and fixture consumers use it.
- Default Toc uses its statically imported target; custom host Toc retains its separate server render path.
- Mapped PresetGenerator fallback now returns a Fragment around its fixed boundary. Staged configured bootstrap imports the existing public facade, not an unexported controller subpath.
- Public type guidance and EN/JA documentation explain the seam migration. Tests retain host precedence, no-marker/no-shim settings cases, serialized locale/date formats and fallback isolation. New real-build cases exercise a supplied host boundary on injected and self-contained routes with default suppression and feature on/off.
- Smoke router-race content uses `rawHtml` for its unchanged static script; the race assertion is unchanged.

Independent review checked target identity, settings precedence, configured-route host precedence, the independent hostpanel case, and fallback transport. No unpublished dependency, alias shim, registry bypass, discarded override, or snapshot blessing was added.
