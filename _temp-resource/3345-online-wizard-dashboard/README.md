# Epic 3345 planning resources — Online Wizard + Dashboard

Accepted round-2 UI prototypes and their shared spec for epic zudolab/zudo-doc#3345.

- `c3-gallery-first.html` — accepted creation-wizard prototype (C3). Reference for the wizard sub-issue.
- `d3-master-detail.html` — accepted dashboard prototype (D3). Reference for the dashboard sub-issue.
- `DESIGN-SPEC-ROUND2.md` — the design spec the prototypes were built against (Surface C + D requirements, sample data).
- `tokens.css` — the prototypes' standalone token set. Conceptual mapping only: the app re-expresses everything in its own `--zdo-*` system.

Open the `.html` files directly in a browser (self-contained; each has a light/dark toggle bottom-right).

The prototypes include fictional affordances (publish states, accent row, feature checkboxes, fake URLs) that the epic explicitly does NOT implement — see the epic body's "Reality adaptations".

**Cleanup rule:** this directory is deleted by the epic's confirm sub-issue before the root PR merges — planning scratch does not outlive the epic.
