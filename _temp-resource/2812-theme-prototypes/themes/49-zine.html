Theming Your Docs

Give your documentation a personality — swap tokens, fonts, and component styling with a single installable theme.

Every zudo-doc site ships with a design-token contract: colors, typography, spacing, and component seams are all expressed as CSS custom properties. A theme is a curated bundle that overrides those tokens — and, when it wants to go further, restyles individual components directly. Install one with zudo-doc theme apply and the whole site repaints.

How themes work

A theme layers on top of your color scheme. It can re-point semantic roles like --zd-accent, swap the reading typeface, attach backgrounds, and re-shape details like admonition borders or heading rules.

Note

Themes are independent from the light/dark mode toggle — every theme defines both a light and a dark palette, and the toggle keeps working.

// zfb.config.ts — pick your theme
import { zudoDoc } from "@takazudo/zudo-doc/config";

export default zudoDoc({
  title: "My Docs",
  themePack: "zine",
  themePackSwitcher: true,  // bottom-right flyout
  maxTocDepth: 3,
});

What a theme controls

LayerTokensExamples
Colors--zd-*backgrounds, accents, syntax palette
Typography--font-*, --zdc-doc-*reading face, heading face & weight
Components--zdc-*admonition shape, card radius, nav marker
Extrasfree CSSpage backgrounds, borders, decorations

Tip

Use the prev / next buttons in the theme flyout to walk the whole collection live on your own content.

Syntax highlighting

Code fences render with semantic token classes, so a theme restyles every language at once: keywords, strings, numbers, and callables each follow their own token.

Good themes change the mood, not the meaning — hierarchy and affordances survive every swap.

Warning

Aggressive themes may restyle components entirely. Check contrast in both modes before shipping to production.

Ready to build your own? Start from any official theme and adjust the tokens — the Design Tokens reference lists every seam.
